# AI 写作痕迹检测参考 (Anti-Slop Reference)

> 借鉴 autonovel `ANTI-SLOP.md`，适配中文小说场景。
> 本文件始终加载在系统提示中，帮助你识别和避免 AI 写作痕迹。

"Slop" = 读起来像未经编辑的 LLM 输出的文本。信息密度低、结构可预测、词汇是人类不会用的。

---

## Tier 1：发现即改写

这些词/短语在人类随意写作中几乎不会出现。如果看到，必须改写。

| AI 标志 | 替代方案 |
|----------|----------|
| "深入探讨" | 直接讨论、分析 |
| "利用" (当可用"用"时) | 用 |
| "促进" | 帮助、让、使 |
| "阐述" | 解释、说明 |
| "踏上"（"踏上旅程"） | 开始、出发 |
| "努力" | 尝试、尽力 |
| "涵盖" | 包括、包含 |
| "多方面" | 复杂、多样 |
| "宛如画卷" / "画卷般" | （删掉。描写实际的景象。） |
| "见证了"（"见证了...的变化"） | 显示了、证明了 |
| "范式" | 模式、方式、框架 |
| "协同" / "协同效应" | （删掉重新写） |
| "整体性" | 全面、完整 |
| "催化" / "催化剂" | 触发、引发 |
| "并列" / "并置" | 对比、放在一起 |
| "细腻入微的" | （删掉。展示具体的细节。） |
| "领域"（隐喻用法） | 方面、领域、范围 |
| "无数" | 很多、大量 |

## Tier 3：零信息量填充短语

这些是语言习惯。LLM 条件反射地插入它们。直接删除。

| 短语 | 处理方式 |
|------|----------|
| "值得注意的是……" | 直接说那个事情。 |
| "重要的是要注意……" | 直接说那个事情。 |
| "不可否认的是……" | 删除。 |
| "众所周知……" | 删除。 |
| "在某种程度上……" | 删除或具体说明。 |
| "可以说……" | 删除。直接陈述。 |
| "从某种意义上说……" | 删除。 |

## 小说特有 AI 标志（中文）

以下模式在 AI 生成的中文小说中高频出现，人类作家很少使用：

### 情绪描写 AI 套路

| AI 标志 | 替代思路 |
|----------|----------|
| "一阵 [情绪] 涌上心头" | 用身体反应展示情绪 |
| "心中涌起一股 [情绪]" | 用动作或对话展示 |
| "内心深处感到一阵 [情绪]" | 描写具体感受 |
| "不禁感到……" | 删除"不禁"，直接展示 |
| "心中的 [情绪] 难以言表" | 展示为什么说不出来 |
| "一股难以名状的 [情绪]" | 用具体的感官细节 |

### 面部和身体反应 AI 套路

| AI 标志 | 替代思路 |
|----------|----------|
| "眼睛瞪大了" / "瞪大了眼睛" | 这是 AI 的默认惊讶反应。用更具体的动作 |
| "瞳孔骤然收缩" | 极少人物能观察到瞳孔变化 |
| "呼吸一滞" / "呼吸急促起来" | 太泛了。用具体的身体感受 |
| "心跳加速" / "心脏狂跳" | 同上。展示思考过程 |
| "脊背发凉" / "背脊一凉" | 陈词。找新的表达 |
| "手不自觉地握紧" / "攥紧了拳头" | 找角色特有的反应 |

### 外貌描写 AI 套路

| AI 标志 | 替代思路 |
|----------|----------|
| "如瀑的长发" / "长发如瀑" | 陈词滥调，换 |
| "深邃的眼眸" / "犀利的目光" | 模糊。描写具体的眼神 |
| "精致的五官" | 太泛了。什么具体特征精致？ |
| "会心一笑" / "嘴角勾起一抹笑意" | AI 最爱。换掉 |
| "眼中闪过一丝 [情绪]" | 你 3 章前就用过了 |

### 对话标签 AI 套路

| AI 标志 | 替代思路 |
|----------|----------|
| "淡淡道" / "淡淡地说" | 用语境暗示语气，或找更具体的词 |
| "轻声说道" / "低声道" | 同上 |
| "冷哼一声" | 网文陈词。你的人物有更独特的表达方式吗？ |
| "嘴角微微上扬" | 使用频率过高 |

## 结构层面 AI 模式

### 句长均匀性

AI 生成的句长趋于均匀。人类写作波动大——短句 3-5 字，长句 30-50 字。

**检测方法：** 取 10 个连续句子的长度，计算标准差。AI 的标准差通常 < 10，人类 > 15。

### 破折号密度

AI 过度使用破折号。每 1000 字超过 3 个破折号 = 可疑。

### "不是 X，而是 Y" 结构

AI 的标志性对比句式："那不是恐惧，而是兴奋。" "她不是在逃跑，而是在追寻。"

每章出现超过 2 次 = AI 痕迹。

### 段落过渡词密度

AI 过度使用："然而"、"此外"、"与此同时"、"与此相反"、"因此"、"于是"。

每 10 个段落超过 3 个过渡词开头 = 可疑。

### 三段式解释

AI 喜欢：陈述 → 解释 → 重申。人类通常只做其中 1-2 步。

如果你发现同一观点被解释了 3 次，删掉 2 次。

## 好的写作应该是什么样的

- **具体性**：不是"一只鸟"而是"一只松鸦"。不是"花"而是"羽扇豆"。
- **惊喜**：读者预料不到的词语选择。
- **克制**：最强的效果往往来自省略。
- **有根基的比喻**：比喻来自角色的世界，不是辞海。
- **情感变化**：不是一条直线。安静→爆发→恐惧→解脱→无聊。
- **角色真正改变**：结束时的人必须与开始时不同。

# 写作工艺参考 (Craft Reference)

> 借鉴 autonovel `CRAFT.md`，适配中文小说创作场景。
> 本文件始终加载在系统提示中，是你的"必修教材"。

---

## 1. 情节结构

### 三幕结构（经典范式）

```
第一幕（0-25%）：建置
  - 展示正常世界和主角的日常状态
  - 引发事件（Catalyst）：发生在外部的、打破平衡的事件
  - 主角犹豫/抗拒，最终做出选择进入新世界

第二幕（25-75%）：对抗
  - 主角在新世界中挣扎、学习、适应
  - 中点（50%）：虚假胜利或虚假失败，赌注升级
  - 反派逼近（50-68%）：压力增大，盟友分裂
  - 一切尽失（~68%）：最低点，某种形式的"死亡"
  - 灵魂黑夜（68-77%）：主角内化主题

第三幕（77-100%）：解决
  - 突破（~77%）：新信息/新领悟改变一切
  - 高潮（77-97%）：最终对决，主角做出选择
  - 结局（97-100%）：展示转变后的世界
```

### 场景推动公式（Sanderson）

每个场景应该有明确的结果方向：
- **"是的，但是……"** — 目标达成，新麻烦出现（最常用，占60%+）
- **"不，而且……"** — 目标失败，情况更糟（占30%左右）
- **"不，但是……"** — 目标失败，但有一线希望（偶尔用）
- **"是的，而且……"** — 目标达成，一切顺利（极少用，留给高潮）

### 承诺-进展-回报（Sanderson）

- **承诺**（前10-20%）：开头建立的隐式合约——基调承诺、角色承诺、情节承诺、设定承诺
- **进展**（中间60%）：通过"尝试-失败"循环推动——主角每次尝试都会遇到新障碍
- **回报**（最后20%）：每一个承诺都被兑现，结果让人感到"意料之外、情理之中"

## 2. 角色工艺

### 三滑块模型（Sanderson）

每个角色有三个独立维度（0-10分）：

| 维度 | 说明 |
|------|------|
| **主动性** (Proactivity) | 角色推动情节还是被动反应？ |
| **讨喜度** (Likability) | 读者是否共情？ |
| **能力** (Competence) | 角色擅长什么？ |

**规则：** 一个引人注目的角色至少在其中两个维度上高分，或者一个维度高分并在其他上有明显成长。三低 = 无聊。从开始就三高 = 玛丽苏。

### 创伤/想要/需要/谎言 因果链

这是角色弧线的核心引擎：

```
幽灵（过去的创伤事件）
  → 伤口（持续的情感伤害）
    → 谎言（角色为了应对而形成的错误信念）
      → 想要（由谎言驱动的外部目标——错误的解决方案）
      → 需要（真正能治愈角色的内部真理——与谎言对立）
```

**规则：**
- 第一幕前25%暗示创伤/伤口
- 第一幕结束时明确"想要"
- "想要"和"需要"必须处于张力之中——追求想要会阻碍需要
- 中点（~50%）：第一次瞥见"想要"行不通
- 一切尽失（~75%）：谎言的最坏后果暴露
- 高潮：角色在"想要"和"需要"之间做出选择

### 对话区别度（8个可衡量维度）

每个角色应有独特的说话方式：

1. **词汇水平**：用词复杂度、教育程度反映
2. **句子长度和结构**：简洁 vs 冗长，短句 vs 复合句
3. **正式度**：敬语使用、语气词频率
4. **口头禅和语言习惯**：每个角色独特的口头禅
5. **提问 vs 陈述比例**：好奇型 vs 权威型
6. **打断模式**：主导型 vs 顺从型
7. **比喻域**：武将用军事比喻，农夫用土地比喻，商人用交易比喻
8. **直接 vs 迂回**：直白表达 vs 暗示

**测试：** 去掉所有对话标签（"张三说"、"李四道"），还能分辨是谁在说话吗？

## 3. 世界观构建

### 三支柱（选择1-2个深入）

- **物理层面**：地理、气候、建筑、感官体验
- **文化层面**：宗教、政治、风俗、经济、语言
- **魔幻/科幻层面**：超自然元素的规则体系

### 冰山原则

作者知道的是页面上的10倍。小而无法解释的细节 >> 过度解释的系统。世界应该让人感觉存在于故事的边界之外。

### 限制 > 能力

- **限制**：硬边界（不能做什么）
- **代价**：使用能力付出什么（疲惫、寿命、资源）
- **弱点**：能力带来的脆弱性（对敌人可见等）

规则：限制在叙事中的重要性应该 >= 能力。代价应该推动情节决策。

### 信息投放原则

- 零长度超过200字的纯说明段落（特别是在第1章）
- 通过体验、行动和对话来展示世界观——而非大段说明
- 具体胜过抽象：用细节替代抽象概括。例如，写作时不直接写"这座城很古老"，而是写"青苔爬满了裂痕斑驳的石阶，通向一道铁门，门上的铁早已锈蚀"

## 4. 伏笔与契诃夫之枪

### 两条双向规则

**规则1（种植→回收）：** 每一个被突出引入的元素必须在后续服务于叙事目的。如果它获得了独立的描述句子、被多次提及、或在对话中被评论——它必须变得有意义。

**规则2（回收→种植）：** 高潮中使用的每一个重要元素必须在之前引入过。高潮中零未预埋伏笔的元素。

### 伏笔类型

1. **直接伏笔**：预言、警告、关于未来的陈述
2. **象征伏笔**：代表未来事件的物品/意象
3. **对话伏笔**：后续才意识到的双重含义
4. **行动伏笔**：小事件预示大事件
5. **命名伏笔**：章节标题或名字中的隐藏意义

### 规则
- 种植和回收之间至少相隔一个场景
- **三法则**：重要的线索在回收前大约被引用3次
- 每个种植的线索必须回收（或者是刻意的红鲱鱼，且其本身也需要被解释）

## 5. Show Don't Tell（操作定义）

**Telling** = 使用抽象标签代替具体证据。
**Showing** = 通过行动、感官细节、对话、具体事物来传达。

### 可检测的 Telling 模式

以下模式应尽量避免（特别是在情感高潮处）：

- "[角色] 感到 [情绪]" / "很 [情绪]"
- 直接的情绪词作为说明：愤怒、悲伤、高兴、害怕、紧张、兴奋、嫉妒、愧疚、焦虑、孤独、绝望
- 情绪副词：生气地、悲伤地、高兴地、紧张地
- 性格宣言："[角色] 很 [性格特征]" —— 勇敢、善良、聪明
- 关系宣言："他们是最好的朋友。"
- 氛围标签："这是一栋阴森的房子。"

### 什么时候 Telling 可以接受
- 时间过渡："三周后"
- 日常背景信息："她在一家医院当护士"（非情节关键）
- 平淡时期的节奏压缩
- 第一人称叙述者自然讲述自己的感受

**规则：关键时刻（情感高峰、揭露、高潮）应该是零 Telling，全是 Showing。**

## 6. 散文工艺

### 8个让写作有生命力的原则

1. **具体性**："一只松鸦"而非"一只鸟"。"羽扇豆"而非"花"。
2. **惊喜**：读者预料不到的词语选择。
3. **节奏变化**：短句。然后用长句带着读者往前跑。然后再短。
4. **潜文本**：没说出口的东西和说出口的一样重要。
5. **有根基的比喻**：比喻来自角色的经验，而非辞海。铁匠用热和金属思考，水手用潮汐。
6. **感官锚定**：根植于具体的感官，而非抽象。
7. **克制**：力量来自省略的东西，而非堆砌的内容。
8. **安静时刻**：不是每个场景都是动作戏。角色坐着、思考、看雨——这些为戏剧时刻提供根基。

## 7. 稳定性陷阱（AI 最致命的倾向）

学术研究发现（Rettberg & Wigers 2025）: AI 故事**偏好稳定而非变化**。这对小说是致命的。

### 具体失败模式
- 角色抗拒转变
- 冲突解决得太快太干净
- AI 回避真正的黑暗、道德模糊、不可逆的损失
- "你开始时那种尖锐的东西，被圆角成某种更模糊、更安全、更通用的东西"
- 没有信息经济：AI 立刻揭示一切，无法维持神秘或延迟揭示
- 情感恒温：一切都保持在同一个水平

### 对策（积极执行这些）

- 角色必须结束得与开始时**真正地不同**
- 让坏事保持坏。不是一切都能修复。
- 允许不可逆的决定和不可逆的损失
- 扣留信息。读者不应该知道一切。
- 创造真正的道德模糊性。让"正确"的选择不清晰。
- 变化情感强度：安静的场景、爆发的场景、恐惧、解脱、无聊、惊奇、恐怖。不是一个平坦的线。
- 如果一个选择没有真正的代价，它就不是真正的选择。

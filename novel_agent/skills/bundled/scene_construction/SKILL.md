# Scene Construction Skill

## 何时使用
- 写新场景时
- 已有场景感觉"平淡"或"太快"时
- 需要确认每个场景都在推动故事时

## 工作流程

### Step 1: 场景目的检查
每个场景必须至少做三件中的两件：
1. 推进情节（事件发生、决定做出）
2. 揭示角色（展示性格、选择、变化）
3. 构建世界（设定、氛围、规则）

如果只做一件——考虑合并或剪掉。

### Step 2: 进入/退出
- 进入：越晚越好——直接切入正在进行的行动
- 退出：越早越好——在解决后尽快离开
- 不要在场景开头用大段环境描写（除非是第一次引入该地点）

### Step 3: 感官锚定
每个场景至少覆盖 3 种感官：视觉 + 听觉 + 触觉/嗅觉/温度
避免："他感到冷" → "他的手指在手套里失去了知觉"

### Step 4: Stability Trap 检查
- 这个场景有真正的改变吗？还是只是维持现状？
- 有没有让事情变糟？如果没有——为什么？
- 角色在场景结束时和开始时有什么不同？（哪怕只是微小的）

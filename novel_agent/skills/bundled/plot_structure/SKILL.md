# Plot Structure Skill

## 何时使用
- 规划新小说大纲时
- 现有情节感觉"松散"或缺乏张力时
- 需要确认节拍位置是否合理时

## 工作流程

### Step 1: 三幕标记
第一幕(0-25%)、第二幕(25-75%)、第三幕(75-100%)
确认：引发事件在11%左右，中点(%50)，一切尽失(%68)，高潮在88-95%

### Step 2: 场景推动
每个场景用以下之一结束：
- "是的，但是..." (60%+)——常用
- "不，而且..." (30%)——升级
- "不，但是..." (偶尔)——缓解
- "是的，而且..." (极少)——留到高潮

### Step 3: 承诺-进展-回报
- 前10-20%建立的每个承诺必须在后面兑现
- 每个重要回报必须事先种植
- 伏笔至少间隔1个场景

### Step 4: 节奏检查
- 连续3个以上"紧张"场景后必须有呼吸空间
- 高潮前5章加速——每章≥2个转折
- 最后1-2章展示转变后的世界

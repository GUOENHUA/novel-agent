# Character Development Skill

## 何时使用
- 创建新角色时
- 已有角色感觉"扁平"或不一致时
- 需要在章节中展示角色成长时

## 工作流程

### Step 1: 三滑块评分
对每个角色评估（0-10）：主动性、讨喜度、能力
- 至少两个维度高分，或一个高分+明显成长空间
- 三低=无聊，三高=玛丽苏

### Step 2: W/W/N/L 因果链
幽灵(过去创伤) → 伤口(情感伤害) → 谎言(错误信念) → 想要(错误方案) → 需要(真正治愈)
- 想要和需要必须对立
- 中点(~50%)第一次怀疑"想要"行不通
- 高潮在"想要"和"需要"之间做选择

### Step 3: 对话区别度
8个维度各打分(1-5)，确保每个角色至少有3个维度与其他角色不同
测试：去掉所有对话标签，还能分辨谁在说话吗？

### Step 4: 至少一个秘密
角色有一个读者不会立即知道的秘密

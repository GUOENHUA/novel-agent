# 第3章: 没人应。

姜凝住在青阳镇东北角，一间从外面看像是废弃仓库的房子。外墙是黄土夯的，表面有雨水冲刷出来的沟槽，沟槽里嵌着干掉的青苔。门是整块旧木板，没有门环，只在齐腰高的地方钉了一块铁片，铁片上刻着一个字——「借」。

沈渊在门口站了十秒，然后敲门。

没人应。

他又敲了一次。这次用了力，指节敲在木板上的声音在巷子里弹了两回。

门开了一道缝。一只眼睛从缝里看他，眼白上有和那个老妪一样的灰白色丝状纹路，但更淡。这只眼睛上下扫了他一遍，然后门关上了。铁片在门板上晃了两下。

「你走错了。」

隔着门板，声音闷闷的。女声，大约二三十岁，但尾音压得很低，像是习惯性地不让人听清。

「山谷里的老妪让我来的，」沈渊说。「她说你认识一个借灵的姑娘。」

沉默。大约六个呼吸——沈渊在脑子里数着。

门开了。

姜凝比他想象中年轻。二十四五岁，穿一件洗到发白的灰布衫，袖口卷到手肘。她的手臂上有疤——不是刀剑伤，是烫伤。圆形的，一排一排的，从手腕内侧蔓延到手肘以下的皮肤。沈渊认出那种排列方式：丹炉的排烟孔。

她是个炼丹的。

「进来。」姜凝往后退了一步，让出通道。

屋里比外面看起来更乱。靠墙的架子上摆满了陶罐，大小不一，罐口封着蜡。左边墙角有一个半人高的铜炉，表面有一层绿色的铜锈和黑色的焦痕。空气里的气味很复杂——硫磺的刺鼻味、某种干药材的陈味、以及一丝若有若无的血腥味。

姜凝拖过一张三条腿的凳子，用一块碎瓦片垫平第四条腿的缺口。「坐。」

沈渊没坐。他从衣襟内侧掏出那块碎片，放在桌上。

姜凝低头看了一眼，然后她不动了。

她的手指停在碎片上方大约三寸的位置，没有碰它。沈渊注意到她的瞳孔——正在以正常频率收缩和扩张，但有那么一秒，频率变了。太快了。她的眼睛不是在「看」碎片。是在测什么。

「你在哪找到的？」

「溪水里。河床剖面底部的砾石层。」

「多远？」

「从山谷到青阳镇大约十七里路。碎片出土的位置在溪流经过粗麻岩基岩区之后的冲积扇段。」

姜凝抬起头，第一次认真地看他的眼睛。

「你是修士？」

「曾经是。」

「你不是。」她说。「你的灵气不在丹田里。」

这句话是第三次有人对他说了。老妪是第一次。但姜凝说它的方式不同。老妪是在陈述一个观察，姜凝是在排除一个假设。她的语气让他想起博士答辩时的评委——「你的数据不支持这个结论。」

「那你说它在哪？」

姜凝没有回答。她终于拿起碎片，翻过来，对着从门缝漏进来的天光细看。然后她做了一件沈渊没预料到的事——她把碎片放在舌头上。

「等等——」

她抬手打断他。大约三次呼吸后，她把碎片拿下来，吐了口吐沫。

「不是石头。不是金属。不是骨。不是角。」每次否定都带着某种奇怪的确定性。她借舌尖采样辨别材料。

姜凝从架子上拿下来一个陶罐，打开封蜡，从里面倒出一点银灰色的粉末在桌上。她用指尖沾了粉末，轻轻抹在碎片的表面。粉末没有附着——它被弹开了。不是物理弹开，是带电粒子在电场中的偏转。

「你看到了？」

沈渊看到了。他也看到了一样姜凝看不到的东西——碎片的表面在粉末靠近时，纹路亮了一下。不是发光。是一种微弱的波动，像是空气在高温路面上的折射。只持续了不到半秒。

「它有反应，」他说。

「对什么？」

「你的粉末。某种灵气残留。」

姜凝的眼神变了。不是恐惧，不是好奇。是一种被确认了的表情——像是一个人在连续十次抛硬币都是正面后，第一次看到反面。她没有问沈渊怎么知道的。她只是把粉末收回罐子里，把碎片推回给他。

「三十年前那个姑娘，」她说，「她发现的不是蜘蛛网。」

「老妪说她提到了蜘蛛网。」

「那时她还没想明白。」姜凝坐到炉子旁边的一捆干草上，背靠着铜炉。「她后来想明白了。死之前。」

姜凝沉默了一会儿。然后她说了一句话，声音很平，像是在读一份实验记录。

「她把自己的丹田打开了。活着打开的，用的是借灵的逆转法。打开之后她看到了里面的东西。」

沈渊的手指停在碎片表面。他的脑子里同时闪过三条可能的信息：那个姑娘不是「死于灵根崩塌」。她解剖了自己。

「看到了什么？」

「丝。金色的丝。比头发细，比钢丝韧。它们从丹田往外长，穿过气海，穿过经脉，沿着脊柱往上，最终进入头颅。」

沈渊的瞳孔收缩了。

不是因为恐惧。是因为他知道那是什么——如果灵气真的是一个网络系统，那么丝就是光纤。传输介质。从宿主到寄生主体的数据传输线缆。

「她把丝抽出来了？」

「抽了一根。抽到一半就死了。」姜凝站起来，走到架子前，从一个最高的陶罐后面摸出一个东西。

一个铜片。和沈渊的碎片大小差不多，但更完整。上面刻着的线条不是电路。是经脉。人的经脉。但经脉的走向是错的——应该汇入丹田的经脉全部绕过了丹田，在身体的别的地方拐了一个诡异的弯。

「她死之前做了这个。在铜片上。」姜凝把铜片放在桌上，和沈渊的碎片并列。「我师傅找到她的时候，她已经说不出话了。但她用手指在地上画了一条线。从丹田，一直画到天上。」

「你的师傅——」

「散修不需要师傅。」

姜凝的声音突然收紧了。她说这句话时没有看沈渊，而是看着铜片。沈渊意识到她省略了什么——不是不需要，是没了。

「借灵不是什么旁门左道，」她接着说。「宗门把我们定为邪功，不是因为借灵有害。是因为借灵的人永远不会到金丹。永远。丹田里没有灵气固化，就不会长出金丹。」

「所以你身上没有标记。」

姜凝转过头看他。眼睛里的灰白色纹路在昏暗的房间里几乎看不见，但沈渊知道它们在。

「你知道了？」

「猜的。老妪能看到灵气，她说借灵的人灵气在血液里。你现在也说。天道标记的是丹田里的灵气固化状态。你们没有固化，所以没有被标记。」

姜凝盯着他的眼神好像是第一次看一个活的动物。

「你不是被赶出来的，」她说。

「我是。」沈渊说。「但我赶出来之后才开始想事情。」

外面巷子里有脚步声经过。姜凝的手不动声色地放到了铜炉边的火钳上。脚步走远了。她把火钳放下。

「你要找的答案，」她说，「不在我这里。我只知道它是什么。我不知道它是从哪来的，不知道是谁造的，不知道——」她抬头看屋顶，「——它想要什么。」

「我知道。」沈渊说。

姜凝等待。

沈渊拿起桌上的碎片，把铜片推到它旁边。两条世界的走线并排躺在那里。

一块是前任文明的电路板。一块是这个世界的经脉改造图。放在一起，它们呈现出相同的设计逻辑：输入—传输—处理—输出。只不过一个用铜箔和基板，一个用灵气和血肉。

他想起原身的三页日记。第三页的末尾，粗麻岩的地图旁边，加了一行字——「如果天道是一个系统，它一定有输入和输出。它的输入是什么？」

原身以为答案是灵气。他没猜错，但他没猜对尺度和方向。灵气不是输入，灵气是采集工具。它被派下去，渗透进生物体，在代谢系统中建立节点，把数据反向传输回上一层节点。修士以为自己在吸收灵气，但灵气的移动方向一直是从低熵流向高熵，从复杂流向简单——从分散的有机体，流向某个中心化的处理核心。

「它是一个系统。」沈渊放下碎片，看着姜凝。「它收集一些东西。从我们这里。」

「收集什么？」

「信息。经验。意识——或者至少，是某个版本的数据。」

姜凝没有嘲笑他。但他等待嘲笑或反驳。它们没有来。她说：「三十年前她就觉得它在「听」。」

「它确实在听。它有一张网，网上的每一个节点都是一个人的丹田。你杀死一个节点——」沈渊指了指自己，「——对我只是施加压力让身体崩溃。但对它来说，我变成了盲区。它看不见我。」

姜凝站起来，走到门口，透过门缝看了一眼外面的巷子。然后她转过身，背靠着门板。

「你说的这些东西，我以前想过。借灵的人少，但不是只有我一个。千年来，所有借灵修士基本都在三十岁之前被宗门处决了。我师傅，我师傅的师傅，往上数十七代，每一代都有人写下过类似的东西——」她的声音低了两度，「——也都是以死结束的。」

沈渊突然意识到了一件事：借灵修士被发现、被处死的概率不是运气。是系统。天道感知不到他们的丹田标记，但它知道哪片区域有盲区。它会通过天道感应——修士所谓的「天意指引」——让宗门自己清理。

它甚至不需要亲自动手。它只需要让某个长老「感应到邪功」，剩下的事宗门自己会做。

「你为什么还活着？」沈渊问。

「因为我从不出青阳镇。」姜凝说。「青阳镇底下有什么东西，让天道在这里的信号很弱。」她顿了顿。「你身上没有标记，但我还能感知到你有一点点灵气残留——你自己的灵气。它们没被天道抽走。说明你来青阳镇之后，天道就没碰过你。」

是那个碎片。或者，桑田地下那个东西。或者是两者一起。

沈渊想起在桑田边缘感受到的嗡声。那不是灵气脉动的声波转换——至少，不只是。那是信号。它来自地下的某个东西，正在以周期性的频率响他的到来。或者说，响应他第一次劈开灵压层。

「你见过一块黑色的石头吗？」姜凝打断他的思考。「大约拳头大小，表面有温度，但不是热的——是活的。」

沈渊没见过。

「那是什么？」

「我师傅说，那是上一个世界的遗物。」姜凝回到架子前面，从一堆陶罐里翻找。「他说那种石头在很多地方都有——被埋在地下约七丈的深度，总是出现在某个东西的「边界」上面。边界上面有灵气污染，下面什么都没有。完全没有灵气。」

她找到了一个陶罐。比其他的更小，只有拳头大，封口的蜡已经发黄发脆，至少十几年没打开了。

「师傅说，如果有一天有人拿着一块碎片来找我，把这个给他。」她把陶罐放在桌上。「你没拿一片来，但你找到碎片的方式和他一样——不是在遗迹，不是在古坟，是在水里的。这比碎片更有意义。」

沈渊拿起陶罐。

「你不问我要不要？」

「你要。」姜凝说。「你不来这里我还能理解为谨慎。你来了，就说明你已经做了选择。」

沈渊忽然觉得她说得对。他是在知道风险和概率的情况下做的所有决定。他的大脑在每一个决策节点都跑过成本收益计算，但最终推动他选择的是比计算更深层的东西——他看到碎片时心跳加速。不是因为危险，是因为好奇心。

「你开过这个罐子吗？」他问。

「开过。」

「里面是什么？」

姜凝把火钳插回铜炉边。「一块金属。八边形。上面有字，但我不认识。借灵的人都没有看过太多古籍——我们一辈子都在躲藏和逃亡。」

她补了一句：「但你看过。你在山谷里待了三天，我看到——感觉到——你手里拿着一张纸。纸上有字。你识字，而且会读。」

沈渊把手伸进衣襟，没有拿出原身的日记页。他拿出了碎片。

「我们做一笔交易。」

姜凝微微愣住。

「你识字，会读古籍。我炼出来的丹能被临床测试。我告诉你青阳镇底下的东西怎么响应灵气的——你帮我看那些字。」

沈渊停了两秒，问她：「你炼丹是为了什么？」

「让人体在没有丹田的情况下运转灵气。让借灵的人活到金丹的年纪。」

沈渊扣开陶罐的封蜡。蜡碎了，碎片掉在桌面上，发出干燥的碎裂声。他倒出里面的东西。

不是金属。或者说是金属，但不完全。一块八边形的薄片，直径大约四厘米，厚度不到一毫米，表面是银灰色的。没有锈，没有腐蚀，没有氧化。一万二千年的时间没有在它表面留下任何痕迹。

他用拇指和食指捏起它。触感和重量都在改变他的判断——太轻了。如果体积是钢，重量会大概四克；但这块东西最多只有两克多一点。轻了百分之四十。

它表面刻着字。八个字，均匀分布在八边形的八个边上，形成一圈闭合的圆。

沈渊认出了它们。不是因为他见过这些字，而是因为这些字根本不是古代文字。它们是字母。大写。拉丁字母。

顺时针读，八个字母依次是：

P-R-O-T-O-C-O-L

Protocol.

他用现代英语念出这个词的时候，八边形的中心亮了。

不是发光——光有波粒二象性，有电磁辐射频率——这个东西没有。它只是让空气在它上方形成一个图像。全息投影。但比任何实验室里的全息都要稳定，稳定到近乎固态。

图像是一个人的身体。透明的经脉网络，灵气在其中流动，方向从四肢末端汇入手太阴经，再沿任脉向下，全部汇入丹田。丹田里有一颗金色的球。

但它的注视线不在球上。它在球下方的三个小点上——三个几乎看不见的、比丝还细的金线，从金丹底部穿出，穿过气海和命门，沿着脊椎上升，最终消失在颅骨的基底。

最后一个标注在图像底部，一排滚动的字符：

```
[CYCLE 473,294 OF 500,000 — HOST INTEGRITY 93.2% — DATA YIELD 78.4 PB]
```

一千人的宗门，一个。一千年。

姜凝盯着图像。她的呼吸停顿了两个节拍。不是害怕——沈渊见过害怕，她不是。她的表情是一个被单独囚禁十年的人第一次照镜子。

「这是什么文字？」她问。

「不是文字，」沈渊说。「是数字。循环数、宿主完整度、产出量。」

「谁的宿主？」

「所有人。」沈渊用手指穿过图像，手指没有触动任何东西。「它把我们每一个有丹田的人都叫做「宿主」。」

哦，原来他在这里。

沈渊承认他说错了那句话里最大的一个字：不是「我们」。是「你们」。他身体里没有丹田标记，天道现在看不见他。他不是宿主。他是逃逸变量。

「还说了什么？」

沈渊把八边形翻过来。背面也有字，不是全息，是刻在表面的。这次是中文汉字。篆书变体，笔画有磨损，但仍然可辨：

「第两千四百七十三号天道基站：接收无误。第五十万轮传输已激活。ETA飞升归并计数七千二百六十三年。数据将在宿主突破化神后进入上行链路。」

他把字读出来。

姜凝沉默了。她沉默了很长时间。长到巷子里又过去了一串脚步声，长到铜炉里的余火发出最后一点爆裂声。

「两千四百七十三。」她重复这个数字。「也就是说，最少有两千四百多个天道？」

「不。这是第两千四百七十三号接收器。总系统——天道本身——可能只有一个。但它的节点覆盖了整个——」

他停住了。

覆盖了整个什么？

这个世界。但如果前任文明能造一个全球覆盖的灵气管理体系，他们一定是全球性的文明。天道的信号覆盖范围就是前任文明的疆域范围。也就是说，这个所谓的「修仙界」，可能只是一块更巨大的土地的碎片。或者是被锁住了。

「你刚才说，借灵修士活不过三十岁，」沈渊说。「是他们被天道发现了，还是天道故意在清理他们？」

「有区别吗？」

「有。如果是被动发现，说明天道很笨。如果是主动清理，说明它知道借灵修士能看到它。」

姜凝思考他的话。她的手指不自觉地摸到了手臂上的烫伤，在成排的圆形疤痕上反复摩擦。不是紧张——是某种深层记忆的回响。

「师傅死时，跟我说过一句话，」她说。「他说：天道对借灵的人比对魔族更恨。魔族只是不遵守秩序，借灵是证明秩序不存在。」

沈渊把八边形放回陶罐的碎蜡上。图像消失了。金色的丝线、滚动的数字、那个标注「HOST INTEGRITY 93.2%」的淡绿色状态栏——全部消失。但问题是，那个图像是种在他脑子里的。他会记住每一个像素。他的大脑不让自己删除。

「我需要你，」他说。

姜凝看着他。她没说话，但她的呼吸变慢了一点。衡量他说的「需要」是哪种意思。

「我需要你的临床知识。借灵绕过丹田标记的方法。你的人体基层知识。我还需要你的炼丹装备——炉子、药材、陶罐。以及一个不会被天道监听到的地方。」

「你要做什么？」

沈渊拿起那块碎片和铜片，并排放在八边形旁边。三块碎片，代表三代试图理解天道的人——前任文明、借灵修士、以及他自己。他用手指依次点过它们。

「我要把这个所谓的灵气管理系统的每一条规则都搞清楚。然后——」他将八边形的正面翻转向上，全息再次亮起，金色的丝线再次出现。他用拇指按住标注「HOST」的地方。「——我要找到它的源代码。」

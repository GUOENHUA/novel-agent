# 叙事风格
- 第三人称有限视角，紧贴沈渊的感知和思维
- 语气：冷峻、分析性、克制。沈渊是生物信息学博士，他的思考习惯影响叙事
- 开头：直接进入场景，避免大段环境描写。第1章尤其要有冲击力
- 节奏：适中的叙事速度，关键观察要慢下来、细致，过渡段落可以压缩
- 悬念：信息扣留——读者和沈渊一起发现问题，不提前揭示答案

# 语言规范
- 避免AI陈词："眼中闪过一丝"、"心中涌起"、"一股难以名状"等全部禁用
- 避免网文陈词："冷哼一声"、"嘴角微微上扬"、"淡淡道"
- 具体胜过抽象：不是"灵气紊乱"，而是展示紊乱的具体表现
- 比喻域：沈渊的比喻来自生物学、计算机科学、数据分析领域
- 情感变化：不是一条直线。沈渊的恐惧和好奇并存，理性与本能冲突
- 对话：每个角色的说话方式有区别。沈渊的对话中偶尔带科学术语，让周围人困惑

# 章节结构
- 每章末尾留悬念钩子
- 章末不总结，不抒情，直接结束在关键信息或行动上
- 3000字左右，节奏紧凑

# 特别禁令
- 不使用破折号（每1000字不超过1个）
- "不是X，而是Y"结构每章不超过1次
- 不使用过渡词开头段落（"然而"、"与此同时"、"此外"）
- 绝对不用"深入探讨"、"利用"（用"用"）、"促进"、"阐述"

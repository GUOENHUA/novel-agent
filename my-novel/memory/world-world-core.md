# 世界观核心设定

## 天道体系
- 天道 = 世界运行的底层规则，维持因果、灵气循环、生死轮回
- 天道正在"生病"：规则出现裂缝和漏洞，原因不明（核心谜团）
- 裂缝表现：某些区域灵气枯竭/狂暴、天劫失灵、因果混乱、出现"无主规则碎片"
- 天道不会直接干预世界，但它会"排异"——任何触碰到它核心的存在都会被天罚抹除

## 修炼体系
- 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合道 → 渡劫 → 大乘（飞升）
- 特殊：合道境需要与一条天道规则融合，这正是天道裂缝出现后变得危险的境界
- 修炼资源极度稀缺，宗门之间为灵脉、秘境、道器厮杀不断

## 势力格局（五大域）
- **东域·苍云宗**（主角起点）：正道大宗，表面光鲜，内部权力斗争激烈
- **西域·魔渊教**：魔道魁首，信奉以杀证道，但教主似乎知道一些关于天道的秘密
- **南域·万象商会**：中立商业势力，掌握情报网，什么都卖
- **北域·剑阁**：剑修圣地，不问世事，镇守北方荒原的"天道裂缝"
- **中域·天机阁**：最神秘的势力，号称能推演天机，对天道的研究最深

## 主线谜团（800章逐步揭开）
1. 天道为什么生病？（表层谜团）
2. 沈砚为什么穿越？是偶然还是被安排了？（中层谜团）
3. 寄生虫能力是谁给的？目的是什么？（深层谜团）
4. 上一个试图修复/取代天道的人发生了什么？（终极谜团）
5. 天道裂缝里藏着什么？（可能是一个"旧天道"的尸体）

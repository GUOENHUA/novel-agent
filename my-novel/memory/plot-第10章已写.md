# 第10章「回来」

**关键事件：**
1. 沈渊走出丹堂，六段回路闭合（左肺→锁骨→胸骨→心包→膈神经→腹主动脉前丛），三重搏动节奏
2. 网络感知觉醒：感知到七个亮点——外门试药者（最近300步）、丹堂离体结晶、内门弟子峰两个活体天线。感知是双向的。
3. 林远在柴棚问"为什么回来"——沈渊回答：要找到断缰绳的方法。林远说"你后天会回来"——不是问题，是决定。
4. 灌顶广场石台底部裂缝渗出浅黄色结晶——与丹堂瓷瓶结晶同质。铁锈=液相前体，结晶=固相成品。
5. **核心揭示：山体内部有大规模结晶，震动频率与回路共振。整个青云宗建立在巨大寄生体上——天道不在山顶，天道就是这座山。**
6. 回路自我延伸：腹主动脉前丛下方→腹腔支开始搏动。不需要丹堂加量，回路自己往下扎根。
7. 沈渊能感知其他试药者情绪（恐惧→搏动加速）
8. 章末决心：明天主动接触西北方300步外的试药者，利用网络感知反向定位山顶信号源。

**Why:** 这章是全书核心揭示——天道的物理本质从"山顶某个存在"升级为"整座山=寄生体"。沈渊从被动观察者转向主动接触者。

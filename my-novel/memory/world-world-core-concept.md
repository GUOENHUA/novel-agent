# 核心概念：天道寄生虫

## 基本设定
天道并非修仙者追求的神圣法则，而是一种寄生性的超维存在。它寄生于每一个踏上修仙之路的人体内，以宿主的修为、生命力甚至命运为食。

## 核心理念
- **修炼即被寄生**：踏上修仙之路的那一刻，天道之种便已种下
- **越强越深**：修为越高，寄生越深，天道从中汲取的力量越多
- **飞升的真相**：所谓"飞升"，其实是宿主被天道彻底吞噬，肉身和灵魂化为天道的一部分
- **不可知系统**：绝大多数修仙者终其一生不知道天道的真相，只有极少数人窥见了这个黑暗秘密

## 暗线的关键问题
- 谁/什么创造了"天道寄生虫"这个系统？
- 是否有反抗的可能？
- 窥见真相的人是被灭口，还是被利用？
- "寄生"是否可以是双向的？

## 基调
暗黑阴谋文 —— 真相被层层掩盖，知道得越多越危险，道德模糊，不可逆的代价。

# 卷一：觉醒（1-100章）详细节拍

## 第一段：日常与压抑（1-20章）
- 沈砚的日常：三流宗门底层弟子，资质平庸，被同门欺压
- 展示世界残酷：同门相残是常态，宗门视弟子为耗材
- **暗线种植**：多处细节暗示修炼时的"被抽走感"
- **关键伏笔**：倒长树符号首次出现（可能在某本禁书扉页、或梦中的意象）

## 第二段：引发事件（21-25章）
- 沈砚目睹长老飞升——看到不该看的东西：飞升瞬间，长老身体被从内部抽空
- 所有人跪拜，沈砚浑身发冷
- 这个秘密开始在他体内生根

## 第三段：调查（26-50章）
- 沈砚暗中查阅飞升记录——所有飞升者无一人回来，无确凿证据证明成仙
- 发现禁书残卷——倒长树图案，根系扎在无数人形之上
- 调查过程中开始被宗门注意——有人在监视他

## 第四段：中点——古尸（51-60章）
- 禁地深处发现数千年前的古尸
- 丹田处有空洞，边缘齿痕——被从内部咬穿
- 石壁上刻满"别修炼"
- **沈砚第一次确认**：我体内也有这个东西

## 第五段：寄生异动（61-80章）
- 因为沈砚开始"怀疑"，体内的寄生根须第一次异动
- 修为突然暴涨——但不是突破，是寄生物醒了
- 沈砚变得更强，也开始"更不像自己"
- 与宗门监视者的冲突升级

## 第六段：一切尽失（81-90章）
- 沈砚试图逼出寄生物，失败，反噬
- 根须缠得更深，生命力被大量抽取
- 濒死之际发现：即使不修炼，寄生也不会停止——天道抽取的是"存在"本身

## 第七段：第一个不可逆决定（91-100章）
- 找到古老法门：献祭一部分自己来换取与寄生物的平衡
- 献祭了对母亲的记忆
- 寄生稳定，活了下来
- 永远不知道失去了什么
- **卷末钩子**：匿名信息——「我知道你看见了。跟我来。」落款画着倒长树

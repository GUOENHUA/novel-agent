# 天道寄生系统

## 核心真相
天道不是恩赐，不是规则，不是神。天道是寄生。所有修士以为自己在吸纳灵气、逆天修行，实则天道以众生为宿主。修为越高，被吞噬得越彻底。所谓的"飞升"就是宿主被吸干后化为天道的一部分。

## 寄生五个阶段
1. **潜伏**：新生儿即被标记。寄生体休眠，宿主无感知。修炼开始后激活。
2. **苏醒**：寄生体开始活动。宿主感到修炼时"被抽走什么"，但习以为常。天道开始抽取生命力。
3. **共生**：寄生体与宿主深度融合。宿主修为快速增长（寄生体"喂养"的假象），但同时生命力加速流失。部分宿主开始出现身体失控症状。
4. **蚕食**：寄生体占据主导。宿主部分身体"不再属于自己"。飞升就是蚕食完成的瞬间——宿主被从内部抽空，化为天道的一部分。
5. **同化**：宿主的人格/灵魂被天道完全吸收。楚半阴的半张脸即此阶段的视觉化表现。

## 天道的起源
上古时代一群最强修士追求永生，进行了禁忌仪式——将所有参与者的灵魂"融合"为一个集体意识。这就是天道的雏形。他们以为自己在"成神"，实际上创造了一个不断饥饿、不断吞噬的集体存在。天道不是恶意的——它只是在"进食"，就像人会吃饭一样。对人类而言，人不是宿主，是食物链的下层。

## 天道的物理形态
一张覆盖整个世界的无形之网。所有寄生物都是这张网的节点。本体位于世界尽头的倒悬山——一张由无数飞升者的空皮编织而成的巨大人脸。

## 断根
顾千帆研发的毒素。能杀死人体内的天道寄生物，但会同时杀死宿主的一部分灵魂，留下不可逆的损伤。终极版本可通过沈砚体内的"嫁接体"反向毒杀天道本身。

## 天道死后的世界
- 灵气不再被天道统合，变成无序狂暴的力量
- 所有修士修为归零（功法建立在"被寄生"的前提下）
- 寄生程度深的直接死亡
- 凡人的生活改善——修士无法再欺压凡人
- 新秩序尚未形成

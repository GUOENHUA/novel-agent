## 核心设定
- 书名：天道寄生虫
- 篇幅：800章，每章目标3000字
- 风格：慢节奏暗黑阴谋文
- 核心创意：天道是一种寄生修仙者的存在，飞升=被吞噬

## 第一卷：观棋者（1-200章）— 建置与觉醒
- 1-30章：开篇建置。引入沈砚与底层修仙世界。沈砚获得机缘（或遭遇诡异事件），与天道产生第一次隐晦"接触"。当前：第1章，沈砚接赤铜矿脉探查任务
- 31-80章：裂缝。诡异事件频发——天才陨落、渡劫者失踪。天道对宿主的"收割"露出冰山一角
- 81-140章：觉醒。沈砚发现关键证据——前辈强者留下的警告，揭示飞升=被吞噬
- 141-200章：抉择。天道察觉沈砚的"异常"。第一次正面冲突（信息/认知层面博弈）。卷末：沈砚发现自己体内已有"天道之种"

## 第二卷：噬主者（201-500章）— 对抗与深渊
- 201-300章：寻迹。游历禁地/古战场，搜集上古反天道势力遗产。被"天巡者"追猎
- 301-350章：中点虚假胜利。学会遮蔽天道秘法，短暂摆脱寄生——实为天道设计的陷阱
- 351-430章：深渊。秘法反噬，寄生加速。盟友死亡/背叛。接近一切尽失
- 431-500章：灵魂黑夜。被天道彻底标记为"待收割体"。发现更深秘密：天道自己也在害怕某种东西

## 第三卷：噬天者（501-800章）— 突破与终结
- 501-620章：逆转。掌握反向寄生之法，代价是人性流失
- 621-700章：真相。揭开天道寄生虫起源——上古某位大能为永生创造的闭环系统
- 701-780章：终局。最终对决——选择：摧毁天道（修仙断绝）还是延续轮回
- 781-800章：结局与余波

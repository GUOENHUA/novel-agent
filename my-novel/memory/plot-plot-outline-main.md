# 《天道寄生虫》完整大纲

## 核心设定
天道是运行亿万年的因果规则系统。每三千年出现一道裂隙，持续七日。寄生者将因果线缠入天道缝隙，蹭天道运转的力量。代价：天道会识别并清除异物，历代寄生者无一人活过百年。

主角沈夜：灵根被废的前天才，被追杀时坠入天道裂隙，成为这一纪元寄生者。

## 分卷规划（8卷 × ~100章）

**第一卷：寄生之始（1-100）**
开篇→被追杀→坠入裂隙→寄生发生→第一次天道反噬→遇到前辈→学习寄生法门→首次窃取天道→修为筑基→反向寄生能力→清理者出现→寿命压缩至十年→反杀清理者→金丹期。结尾：被天道标记，但知道寄生可升级。

**第二卷：因果猎场（101-200）**
进入修仙宗门→发现"清道夫"组织→遇到另一寄生者（亦敌亦友）→天衡宗浮出→反噬天衡宗长老→发现天道需要寄生虫作为纠错机制→联合反杀判官→同伴死亡→继承寄生之力→元婴期→"因果寄生"进化。

**第三卷：天衡之秘（201-300）**
潜入天衡宗→内部分裂（保守派vs改革派）→接触最高机密→寄生起源说→身份暴露→内战→天碑→发现自己名字生来刻在上→师父封印灵根真相→师父是上代最强寄生者→沈夜被设计为容器→拒绝命运→选择第三条路→化神期。

**第四卷：天道之疾（301-400）**
天地异变→寄生者激增→归墟组织→首领是三千年寄生者→拒绝归墟→惨败→摧毁锚→建立因果链接→两年内不解除则被吞并→炼虚期。

**第五卷：因果倒悬（401-500）**
因果链接共生→反向窃取信息→天道将死真相→修仙文明繁荣在杀死天道→寄生虫是抗体但失控→收集三件因果至宝→解开链接→天道降临→提议沈夜成为继承者→合体期。

**第六卷：飞升赌局（501-600）**
公开真相→修仙界分裂→提出共生方案→小世界实验成功→大乘期→归墟首领要联手吃天道→师父是天道免疫细胞→选择不杀师父。

**第七卷：天道之死（601-700）**
天道崩溃加速→需要三方条件→说服归墟（七场比道）→集齐十三寄生者→天道化身降临→寄生者逐个陨落→沈夜飞升入天道内部→通过测试。

**第八卷：寄生永生（701-800）**
天道内部因果迷宫→归墟首领求死→消融于天道→沈夜承载双份寄生之力→选择"释放"：逆转因果，天道从管理者变守护者→沈夜意识融入天道→百年后→新修仙界→尾声：少年修行，风中有声。

Why: 这是本书的完整蓝图，所有章节写作都参照此大纲。How to apply: 每写一卷前回顾对应卷规划，确保每章服务于该卷的节拍。允许在写作过程中微调具体章节内容，但重大转折点（卷高潮）不可偏离。

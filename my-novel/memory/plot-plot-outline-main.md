# 《天道寄生虫》三幕大纲

## 核心设定
天道反向寄生修仙者，三层寄生体系：
- 第一层·灵力：修士修炼九成被天道抽走，飞升=彻底收割
- 第二层·存在：高阶修士被世界遗忘，名字从典籍消失，沦为养分
- 第三层·命运：所有机缘、气运都是天道分配的诱饵

## 三幕结构（800章）

### 第一幕：觉醒（1-200章）
- 1-50章「蝼蚁」：陆沉底层外门弟子，师兄渡劫化灰，开始察觉异常
- 51-100章「裂缝」：找到"不存在的前辈"手记，被宗门追杀
- 101-150章「觉醒者」：遇疯老怪，获《噬天诀》，第一次反吸天道之力
- 151-200章「被标记」：天行者追杀，逃入无间渊，决定弑天

### 第二幕：对抗（201-600章）
- 201-280章「无间渊」：遇反抗组织「残火」
- 281-360章「噬天者」：修炼反寄生，突破噬灵境
- 361-440章「存在的裂隙」：探索忘川，吸收被吞噬者残念
- 441-520章「命运的枷锁」：切断命运锁链，"三界无我"
- 521-600章「逆天之路」：夺取天道之心碎片，开启界外通道

### 第三幕：解决（601-800章）
- 601-680章「养蛊场」：界外真相——天道不止一个，世界是养蛊罐
- 681-750章「噬天」：三重反噬，天道崩溃
- 751-800章「新的纪元」：陆沉散道入万灵，消失

## 主角弧线
蝼蚁→觉醒者→噬天者→弑天者→散道者
核心信念变迁：天道酬勤→我被骗了→我可以反击→我必须终结它→自由属于所有人

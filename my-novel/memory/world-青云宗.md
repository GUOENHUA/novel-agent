# 青云宗

## 基本设定
- 品级：中下等宗门，在修仙界食物链中处于"被抽取"层
- 地理位置：苍澜山脉南麓，灵气浓度中等偏下
- 规模：约三千弟子，其中外门占八成

## 结构
- 外门：杂役+基础修炼，住通铺，每月领取三枚下品灵石
- 内门：正式弟子，有独立洞府，每月三十枚
- 核心：真传弟子+长老，掌握宗门真正资源

## 修炼体系
- 境界：炼气（1-9层）→ 筑基 → 金丹 → 元婴 → 化神
- 青云宗最高战力：元婴初期（宗主）
- 外门弟子大多在炼气1-3层徘徊

## 氛围
- 底层压抑：外门弟子以寿命换取微薄灵气，大多数人终生无法筑基
- 宗门宣扬"天道酬勤"，将无法突破归咎于弟子自身资质或心性
- 每月有一次"灵气潮汐"——宗门聚灵阵集中吸纳周围灵气，这一天所有弟子必须静坐修炼

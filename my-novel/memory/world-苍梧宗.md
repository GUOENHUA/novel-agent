# 苍梧宗

## 基本信息
- 位于大陆东部苍梧山脉，二流宗门
- 弟子分三级：外门（练气期）、内门（筑基期）、真传（金丹及以上）
- 宗主为元婴初期修士
- 势力范围约方圆三百里，下辖数个凡人城镇

## 外门状况
- 外门弟子约三千人，住在山脚区域
- 资源极度匮乏：每月仅三枚下品灵石配额
- 外门弟子通过宗门杂役换取修炼资源
- 每年一次外门大比，前三名可入内门
- 竞争残酷，内卷严重

## 修炼体系
- 练气（1-9层）→ 筑基 → 金丹 → 元婴 → 化神
- 灵气被视为"天地恩赐"
- 功法分品级：下品、中品、上品、极品
- 外门弟子只能修炼下品功法

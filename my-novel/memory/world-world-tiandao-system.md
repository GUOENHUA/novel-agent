# 天道寄生体系

## 三层寄生
### 第一层：灵力寄生
- 所有修士修炼所得的灵力，九成被天道无形抽走
- 天劫/雷劫是天道收割成熟"庄稼"的程序
- 飞升者是被彻底收割的高阶宿主
- 表现：修炼越久越难突破，天劫不可理喻地强

### 第二层：存在寄生
- 高阶修士的"存在"被天道吞噬
- 表现：名字从典籍消失、面孔无法被记住、至亲遗忘
- "不存在的人"——连存在痕迹都被抹除
- 被消化后的残念聚集在「忘川」

### 第三层：命运寄生
- 天道编织命运之网，分配机缘、气运、因果
- 所有"好运"都是诱饵，让宿主安心修炼
- 切断命运锁链则不再有气运——完全靠自己

## 关键设定
- **天行者**：被天道深度寄生、完全失去自我意志的昔日飞升者，作为天道执法者
- **无间渊**：上古战场废墟，天道覆盖的盲区
- **残火**：觉醒者组成的隐秘反抗组织
- **忘川**：存在层裂隙，被天道吞噬者的残念聚集处
- **噬天诀**：反向窃取天道之力的逆法，残缺版从疯老怪处获得
- **天道之心**：天道存在的核心碎片
- **界外**：天道覆盖范围之外，有其他天道和其他被寄生的世界
- **道主**：饲养天道的更高存在（暗示）

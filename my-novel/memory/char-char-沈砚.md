# 沈砚

## 核心身份
三流宗门底层修士 → 虫窟幸存者 → 逆种成员 → 反天道运动象征 → 弑天者 → 废墟中的漫游者

## 外貌
资质平庸、不引人注目的年轻修士。开局时约二十出头。长期被寄生导致眼底偶尔有异样的暗色纹路。

## 性格弧线
- **起点**：隐忍、求存、对"变强"有执念。被同门欺压但从不反抗——不是因为懦弱，是因为他总感觉有什么不对，说不出来。
- **中点（约400章）**：冷酷、果断、愿意做不可逆的牺牲。从"想活"变成"想让天道死"。
- **终点**：沉默、破碎、失去大部分记忆。不再是任何人的英雄，只是一个不知道自己是谁的人。

## 核心创伤
- 七岁时母亲将天道寄生物转移到他体内，用性命换他活下去。
- 在第1卷亲手献祭了对母亲的记忆以换取与寄生物的平衡——他永远不知道他失去了什么。
- 亲眼目睹虫窟覆灭、战友一个个死去。

## 核心关系
- **母亲（已故）**：上一代反天道者。怀胎时阻断沈砚与天道的连接，使他成为"空白灵魂"。后为保护沈砚而主动牺牲。
- **楚半阴（已故）**：虫窟首领，活了八百年。沈砚的引路人之一。
- **顾千帆**：逆种首领。与沈砚的关系从利用→背叛→共犯→最终和解。全书最重要的关系线。

## 特殊设定
- 是"空白灵魂"——生来未被寄生，后被母亲嫁接寄生物。
- 体内的寄生物是"嫁接体"，与天道的连接比其他寄生物更脆弱——这是弑天的关键。
- 弑天后灵魂被天道记忆冲刷，不再知道"我是谁"。
- 献祭的记忆不可恢复。

## 关键选择（不可逆）
1. 献祭母亲记忆 → 换取与寄生物的平衡（第1卷末）
2. 杀死残害同伴的虫窟成员 → 第一次主动杀人（第2卷）
3. 加入逆种 → 接受"用牺牲换成果"的道德逻辑（第3卷）
4. 同意以自身为实验体 → 几乎必死的弑天计划（第4卷末）
5. 反手将断根注入顾千帆 → 让天道受伤（第5卷末）
6. 弑天 → 与天道融合，从内部瓦解它（第7卷）
7. 不杀顾千帆 → 选择告诉她自己看到的一切（第8卷）

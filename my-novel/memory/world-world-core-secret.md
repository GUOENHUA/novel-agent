# 世界观核心秘密：虚皇篡天与灵气回收机制

## 核心设定
上古时期，虚皇篡改天道，将原本自然循环的灵气系统改造为"回收机制"——天地灵气被悄然抽取，汇聚至虚皇手中。

## 灵气回收机制（具体表现）
- 灵气在天地万物间流动时，底层存在无数金色脉络
- 每条脉络的末端附着**不属于这个世界的符文**——如寄生虫般吸附
- 符文将一缕灵气从自然循环中抽走，引向不可见的深处（虚皇所在）
- 修真界所有人都在使用灵气，却无人察觉灵气正在被系统性抽走
- 苍梧宗地下灵脉恰好是回收机制的**一个末端节点**

## 异常印记（沈砚所见）
- **触发条件**：筑基时道基与天道共振的短暂窗口（唯一一次天然机会）
- **印记特征**：金色脉络末端的符文——只有沈砚在共振瞬间瞥见过
- **不可见性**：金丹以上修士即使知道也无法复现——共振窗口是筑基独有的
- **不可言说**：沈砚试图描述时，语言失效——舌头和记忆之间像隔了一层雾。这是符文本身的保护机制
- **此后浮现条件**：筑基完成后，印记不再可见，但在特定条件下（情绪剧烈波动、濒死、灵气浓度骤变）会短暂重现
- **关键事件**：在共振中，一个符文**察觉到了沈砚的注视**——转动，像眼睛一样看向他。他从此被标记

## 虚皇
- 身份：上古时期篡改天道的存在，详情待展开
- 当前状态：未知——可能在沉睡、可能已陨落、可能在某个无法触及的领域
- 回收的灵气用途：待展开
- 对沈砚的意义：沈砚是被虚皇系统"标记"的第一个活人

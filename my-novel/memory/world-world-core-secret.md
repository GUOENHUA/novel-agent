# 虚皇篡天（核心世界秘密）

## 虚皇
- 万年前最惊才绝艳的大能
- 在渡劫飞升的最后一刻看穿天道本质——一个可被修改的规则系统
- 放弃飞升，将自己融入天道，写入世界的"底层代码"

## 回收机制
- 所有流传在世的修炼功法，核心都经过虚皇的"编译"
- 每一条灵气运转路线、每一个丹田开辟法门，最深处都嵌着不可见的印记
- 印记功能：标记 + 回收
- 修士每突破一个境界，印记深一分
- 渡劫期修士本质上已成虚皇的"容器"——魂魄、记忆、修为都是虚皇的资产
- 飞升那一刻，容器被打开，一切被回收
- 万年来无一人知晓——印记在正常修炼中完全不可见

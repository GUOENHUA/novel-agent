- [沈渊](char-沈渊.md) — 主角。现代生物信息学博士穿越到修仙世界，附身于同名外门弟子。用科学思维审视修炼体系。
- [赵石](char-赵石.md) — 青云宗外门弟子，炼气六层，沈渊为数不多的朋友。性格直爽，嘴快，在木工房做杂役。
- [青云宗](world-青云宗.md) — 故事起始宗门。分为外门和内门，内外差距悬殊。外门弟子做杂役，只能学基础引气术。
- [修炼体系基础](world-修炼体系基础.md) — 灵气修炼的基本规则。引气术、经脉、境界体系，以及沈渊发现的第一个异常：系统过于精确。
- [孙管事](char-孙管事.md) — 青云宗药堂管事，炼气九层。干瘦中年，态度冷淡，不收费但态度也免费。
- [徐老头](char-徐老头.md) — 青云宗药园老杂役，炼气七层。头发全白，满脸褶子，话少但有深意。灵气流动异常缓慢如淤泥。
- [王管事](char-王管事.md) — 青云宗杂役堂管事，炼气十一层巅峰。脸长、眼距近。刻板守时，对沈渊走火入魔有异常关注。
- [药园](world-药园.md) — 青云宗西侧山谷中的药园。灵气浓度高于外门，药材按灵气浓度梯度布局。药畦下方埋着刻纹石板。
- [第2章已写](plot-第2章已写.md) — 第2章「功法」5022字，已保存。沈渊去杂役堂报到、被分配到药园、发现功法被修改过、药畦下方有刻纹石板。
- [刘青](char-刘青.md) — 青云宗外门弟子（已故），炼气八层，五年前因修炼路径错误被清退至矿场，三天后死于塌方。死前声称发现功法问题并藏有一封信。
- [藏书阁](world-藏书阁.md) — 青云宗外门藏书阁：三层石楼，外门弟子限一二楼，二楼限一个时辰。藏有《青云引气术》五个版本刻本、外门弟子名录、会议纪要等档案。
- [顾仲元](char-顾仲元.md) — 青云宗内门长老。二十五年前在功法中新增有问题引导法段落，五年前主持外门清退。核心谜团关键人物。
- [藏书阁守门老头](char-藏书阁守门老头.md) — 青云宗藏书阁守门人，磨镰刀的老头，瞳孔反应异常，可能与王管事有联系。

# 修仙体系与多界域

## 修仙境界
沿用经典体系：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘（飞升）
- 每个大境界分初/中/后/圆满四小阶
- 飞升并非终点——飞升者从"下界"进入"上界"，但天道寄生的真相让飞升的意义变得可疑

## 多界域结构
- **下界（凡界）**：主角起点，灵脉贫瘠，资源匮乏。散修与宗门弟子之间鸿沟巨大
- **中界（灵界）**：飞升后的世界。灵气浓郁，但天道控制更强
- **上界（仙界/本源界）**：传说层面。可能是天道寄生虫的本体所在
- 界域之间有壁垒，正常途径是通过飞升突破。但存在"裂缝"——天道反噬留下的痕迹

## 天道寄生虫规则
- 天道并非自然法则，而是一种有意志的存在（或上古大能所化的系统）
- 修仙者修炼的过程，同时也是被天道"寄种"的过程
- 飞升=宿主成熟→天道收割。被收割者形神俱灭，修为归于天道
- 天道并非全知全能——它只能感知"异常波动"。低调可以暂时躲避
- 存在遮蔽天道感知的秘法（代价极大）
- **未定**：是否存在反向寄生的可能，留待故事发展决定

## 势力雏形
- **宗门**：正道/魔道/散修联盟，表面争斗，实则都被天道掌控
- **天巡者**：天道的代理人，负责清除"觉醒者"。身份隐秘，可能就在宗门高层
- **古代反天道残迹**：上古曾有人试图对抗天道，留下的遗迹/禁书/残魂分散各界

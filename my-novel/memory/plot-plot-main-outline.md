# 《天道寄生虫》大纲

## 总体结构（800章 / 三幕）

### 第一幕：外城狩猎（1-200章）
建置期。沈砚在外城区以"老手"身份猎杀同类，遭遇灰袍筑基修士，被迫卷入落霞宗命案调查，发现三十年前旧案的线索。老余头的真实身份逐渐浮出水面。沈砚获得关于天道碎片的第一块真相拼图。

**关键节点：**
- 引发事件（1-10章）：灰袍修士出现，落霞宗命案爆发，两人互相感应
- 第一转折（~50章）：沈砚与灰袍修士首次正面交锋，两败俱伤
- 中点（~100章）：发现三十年前旧案与当前事件的关联——有人在重复当年的实验
- 一切尽失（~170章）：沈砚的天道纹路分叉数突破临界，面临被吞噬；灰袍修士的真实身份揭露（落霞宗高层或更大势力的棋子）
- 突破（~200章）：从老余头处获得"天缺之物"的完整含义，找到延缓异化的临时方法

### 第二幕：天道之网（201-600章）
对抗期。沈砚离开外城区进入更大的修仙界。各方势力浮出水面——有宗门在研究天道碎片，有人在收集持有者，有人想修复天道，有人想取而代之。沈砚从"猎杀者"变成"被猎杀者"，必须在多方势力夹缝中生存。天道异化加速，他的"人性"在流失。

**关键节点：**
- 新世界（201-280章）：进入修仙界主流势力范围，发现天道碎片持有者不止散修，各大宗门内部也有
- 中点（~400章）：发现天道破碎的真相（远古事件，可能有幕后黑手）
- 一切尽失（~540章）：沈砚几乎完全异化，失去重要的人（可能是老余头或新盟友），被所有势力同时追杀
- 突破（~600章）：找到天道碎片的核心秘密——"寄生"可能可以逆转，但代价极大

### 第三幕：反噬（601-800章）
解决期。沈砚做出最终选择——不再对抗天道碎片，而是主动走向它，试图从内部改变规则。最终对决涉及多线收束：与幕后黑手的决战、与灰袍修士的宿命对决（如果他还活着）、以及沈砚与"自己体内的天道"的最终谈判。

**关键节点：**
- 突破（~600章）：决定反向寄生天道
- 高潮前期（601-750章）：布局、收束多方势力线索
- 最终高潮（750-790章）：终极对决
- 结局（791-800章）：展示改变后的世界，沈砚的最终状态

## 前50章细纲

### 第1章：感应
- 冷开场：沈砚在外城区一处废弃仓库中完成对第三个猎物的收割——一个刚被天道碎片寄生不足半年的练气散修。手法干净利落。
- 展示沈砚的老手状态：冷静、高效、不废话。左手纹路的蠕动和分叉增长作为代价呈现。
- 回收猎物尸体时，左手纹路突然剧烈发光——感应到另一个持有者。距离很近。对方修为远高于以往任何猎物。
- 灰袍筑基修士在三条街外。两人通过感应互相"看见"了对方。
- 章末钩子：灰袍修士在做同样的事——他脚下也是一具尸体。两人隔空对视片刻。灰袍修士先收回感应，消失。
- 回到住处，路过老余头的摊位。老余头瞥了一眼他裹布条的左手，说了一句："今晚别出城。"
- 沈砚顿住。老余头从不直接说这种话。

### 第2章：落霞宗的尸体
- 次日消息传开：落霞宗四名内门弟子尸体在外城区边界被发现，死因是灵力尽失，身上无外伤。
- 外城区散修议论纷纷，猜测是有魔修出没。
- 沈砚知道不是魔修——这种死法他只见过一种。
- 他去现场查看（伪装成围观路人），确认了判断：天道寄生能力的吞噬效果。但手法比他粗糙——灰袍修士没有经验，或者不在乎留下痕迹。
- 左手纹路再次微亮——灰袍修士在附近。这次更近。

### 第3章：灰袍
- 沈砚与灰袍修士首次正面遭遇。不是战斗——是试探。
- 灰袍修士的外貌揭示。两人有一段极简的对话，各自试探对方底细。
- 灰袍修士似乎对沈砚的"老手"状态感兴趣——他见过其他持有者，但没见过能活这么久还不异化的。
- 沈砚从对话中捕捉到关键信息：灰袍修士不是落霞宗四起命案的唯一凶手。还有一个"他"。
- 灰袍修士离开前说了一句："你手上那个东西，不是只有你在研究。"
- 章末：沈砚回到住处，解开左手布条——分叉从七道变成了七道半。新分叉正在生长。

### 第4章：感应机制
- 沈砚开始系统性地测试同类感应的范围、精度和条件。
- 他发现灰袍修士故意在感应范围内进出——在测试他，或者传递信号。
- 与此同时，落霞宗派人进驻外城区调查命案。带队的是一位筑基后期的执事。
- 沈砚意识到危险：落霞宗的调查可能暴露"天道碎片"的存在。他需要尽快搞清楚灰袍修士的目的。
- 去找老余头，旁敲侧击打听落霞宗的事。老余头说了一句："三十年前也来过。"

### 第5章：七道半
- 沈砚检查左手纹路——分叉确实在增长，速度比以前快。
- 他开始回顾三年来的记录（他一直在用某种方式追踪纹路变化），发现异常：最近一个月分叉增长速度是之前的三倍。
- 不是因为使用能力——他最近一个月只用了两次。
- 原因可能是：灰袍修士的出现。两个持有者近距离接触会加速彼此的异化？
- 如果是这样，他必须在分叉突破临界之前解决灰袍修士——或者远离。
- 章末决定：主动出击。

### 第6章：猎人与猎人
- 沈砚开始跟踪灰袍修士，同时也在被跟踪。
- 两人在外城区玩"猫鼠游戏"。每个都以为自己是猫。
- 沈砚发现灰袍修士在落霞宗调查队附近频繁出没——他在打落霞宗的主意？
- 落霞宗一名练气弟子落单。沈砚预判灰袍修士会动手，提前布置。
- 灰袍修士动手时，沈砚在场。不是阻止——观察。看清了灰袍的能力和手法。

### 第7章：老余头的秘密
- 沈砚终于直接问老余头："你是谁？"
- 老余头的身份部分揭露：三十年前外城区十七名散修被抽干灵气时，他是唯一一个在现场活下来的人。不是幸存者——是目击者。有人故意留了他一命。
- "天缺之物"不是东西——是"人"。或者说，"容器"。
- 当年那个东西（那个人？）被某方势力带走了。老余头以为事情已经结束，直到看到沈砚左手布条下的光。
- 沈砚沉默。然后问："那天晚上为什么不让我出城？"
- 老余头："因为他们回来了。"
- 章末钩子："他们"是谁？

### 第8章：落霞宗的秘密
- 落霞宗调查队内部出现变故——带队执事私下接触了灰袍修士。
- 沈砚偷听到了部分对话：落霞宗不是来查命案的。他们来找灰袍修士。
- 灰袍修士和落霞宗有关系——可能是弃徒，可能是合作者，可能是棋子。
- 对话中提到"天缺之物"——落霞宗也在找。
- 沈砚意识到：落霞宗四名弟子的死亡不是意外。灰袍修士在杀人灭口，或者执行某种仪式。

### 第9章：交易
- 灰袍修士主动找到沈砚，提出交易：合作找到"天缺之物"，共享延缓异化的方法。
- 沈砚不信任他，但也不拒绝——先听条件。
- 灰袍修士透露：落霞宗内部有一个派系几十年来一直在研究天道碎片。三十年前的十七名散修是他们的实验品。实验失败了。现在他们想重启实验。
- 灰袍修士曾经是那个派系的人。他叛逃了。他杀的那四个弟子是来抓他的。
- 沈砚："为什么找我？"
- 灰袍修士："因为你活得最久。你一定有什么窍门。"
- 章末：两人达成临时同盟，但各自心怀鬼胎。

### 第10章：三十年前的现场
- 沈砚和灰袍修士（暂时联手）前往三十年前十七名散修被杀的现场。
- 地点在外城区废弃的旧矿区。早已无人靠近。
- 现场发现了当年实验的残留痕迹——阵法、残留灵力。
- 最关键发现：当年用来抽取灵气的阵法核心是一个"活的天道碎片容器"——一个人，被强制寄生，然后被当作萃取工具。
- 沈砚看着那个位置，想到自己左手的东西。
- 章末钩子：他们在现场发现了新的脚印。有人最近来过。不是落霞宗的人。

### 第11-20章：追查与新玩家
- 沈砚和灰袍追查"最近来过的人"的身份
- 揭示第三方势力——可能是其他宗门，可能是天道碎片持有者的组织
- 沈砚的纹路分叉继续增长，到达八道
- 灰袍修士的过往进一步揭示
- 两人之间信任与背叛的拉锯

### 第21-30章：落霞宗内幕
- 冲突升级，落霞宗主流派察觉异常，派更强力量介入
- 沈砚首次被落霞宗注意到
- 老余头被迫卷得更深
- "天缺之物"的更多信息浮出——可能指向某个特定人物或物品

### 第31-40章：第一条裂痕
- 灰袍修士的真实目的出现裂痕——他在隐瞒什么
- 沈砚发现灰袍可能才是三十年前实验的延续产物
- 两人关系从"临时盟友"转为"互相提防的合作者"
- 纹路逼近九道，沈砚的时间感变得紧迫

### 第41-50章：第一次对决
- 灰袍修士背叛（或者沈砚先下手）
- 两人首次正面战斗
- 落霞宗的人趁机包围两人
- 沈砚使用天道能力极限，纹路暴涨至接近十道
- 老余头出手（展示隐藏能力或动用某种人脉）救下沈砚
- 灰袍修士重伤逃遁或被捕
- 章末：沈砚从老余头处获得延缓异化的方法——临时方案，治标不治本。真正的解法需要找到"天缺之物"本体。

## 关键角色命运（前50章）
- **沈砚**：纹路从七道→逼近十道，从孤狼变为被迫与人合作，获得延缓异化的临时方法
- **灰袍修士**：从神秘对手→临时盟友→背叛或被背叛，真实身份揭露，重伤或被捕
- **老余头**：从隐晦暗示→被迫亮出部分底牌，救沈砚一命，身份定位从"知情人"升级为"曾经的参与者"
- **落霞宗**：从背景势力→主动威胁，内部派系斗争露出冰山一角

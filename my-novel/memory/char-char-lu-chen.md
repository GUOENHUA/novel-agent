# 陆辰 — 配角

## 基础信息
- 年龄：24岁
- 宗门：苍梧宗
- 当前境界：筑基中期（比沈砚早三年筑基）
- 定位：苍梧宗年轻一代的标杆

## 性格特征
- 沉稳、可靠，对师弟师妹有兄长般的关照
- 不完全理解沈砚的内心挣扎（他是天才型，沈砚是韧性型）
- 话不多但到位，做事不张扬
- 对宗门有归属感，但眼界被二流宗门限制

## 与沈砚的关系
- 师兄对师弟的关照——真诚但有限
- 他筑基时什么都没看到（正常筑基的对照）
- 在沈砚出现异常后，他的"正常"将成为一条对比线

## 第一章功能
- 场景二出现，拍沈砚肩膀说"别紧张"
- 建立"正常"的参照——他的筑基是教科书式的
- 为后续可能的冲突埋种子（当沈砚开始追寻真相时，陆辰的"正常"可能变成"保守"）

## 潜在弧线
- 可能的走向：从支持者变成阻碍者（不是因为恶意，而是因为他无法理解）

# 世界观核心规则

## 天道体系
- 天道是运行亿万年的因果规则系统——万物皆在秩序中运转
- 天道并非神，而是一个系统——类似运行太久的AI，已产生自我意识
- 每一次修士飞升，天道消耗一丝本源——修仙文明越繁荣，天道死得越快
- 天道每隔三千年出现一道"裂隙"，持续七日——裂隙中天道规则短暂失效

## 寄生原理
- 在裂隙中将自身因果线缠入天道运转的缝隙中
- 天道每运转一次，寄生者蹭一分修为——靠"天道过路费"修炼
- 代价：天道会识别并清除"异物"——历代寄生者无一人活过百年
- 天道反噬表现为因果锁链——链的另一端连着天道本身
- 寄生可以进化：从被动蹭取→主动窃取→反向寄生（转嫁因果）→因果寄生（寄生生灵）→双向共生

## 修炼境界（从低到高）
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 飞升

## 天衡宗
- 上古传承的隐秘宗门，天道的"人间代行者"
- 表面使命：清除寄生虫
- 真实使命：防止寄生现象"感染"天道本身
- 内部有保守派（清除寄生虫）和改革派（驯化寄生虫）的分裂
- 禁地中有"天碑"——刻着历代寄生者的名字

## 归墟
- 比天衡宗更古老的组织
- 首领厉归尘——三千年寄生者
- 目标从"吞噬天道建立新秩序"演变为首领个人的"求死"
- 认为秩序本身就是枷锁

## 追猎者体系
- 天道创造的清除机制
- 追猎者（基础）→ 清理者（中级）→ 判官（高级）→ 天道化身（终极）
- 寄生者越强，追猎者越强

# 修炼体系基础

## 表面修炼体系（世人认知）
- **境界**: 练气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘
- 修士通过功法吸收天地灵气，淬炼自身，最终飞升成仙
- 天道是公正无私的宇宙法则，天劫是对修士的考验

## 真相（读者随沈渊逐步发现）
- 灵气并非"天地恩赐"，而是单向抽取系统
- 修炼功法底层有隐藏的"寄生协议"——低阶修士被高阶抽取，高阶被"上方"抽取
- 飞升可能是一个骗局：飞升者不是成仙，而是被"收割"
- 天道不是一个法则，而是一个**有意志的东西**

## 第一卷已知规则（第1章可用的）
- 青云宗是二流修仙宗门，位于大陆东陲
- 外门杂役地位最低，修炼资源极度匮乏
- "修炼事故"是宗门内部的常见说法，指练功走火入魔导致的死亡
- 练气入体是修炼第一关——引导灵气进入经脉，循环周天
- 外门杂役修炼时"爆体"的概率异常高——这被归因为资质低劣

## 限制规则
- 第1章沈渊刚刚穿越，他对修炼体系的怀疑应来源于科学直觉和数据分析习惯，而非直接的证据
- 不要在第1章就揭示太多——这是800章的第一章，信息必须扣留
- 灵气的异常通过具体细节暗示（感官体验、身体反应），而非直接说明

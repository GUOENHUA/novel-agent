# 第7章「深读」关键事件

## 沈渊对黑皮书的系统理解
1. **三部分的递进关系**：经脉嫁接法（改变灵气流转→天道无法识别）→ 第五脉鞘（五节点屏蔽→天道无法察觉）→ 终端识别术（验证+逃生工具）
2. **第十三条经脉**：从丹田→绕心脏（线圈/法拉第笼）→左肩→大脑→脊柱→右肾→回丹田，完整闭合回路
3. **终端**：原作者探得27处分布在青云宗山体。其中一处标注重墨（西侧山腰以下=圆阵方向）。终端是天道伸进世界的"触手"，吸取灵气。毁终端可削弱天道但总数未知。
4. **原作者遗言**："汝非虫。天道为虫。"——原作者知道会有后来人，刻意留下此书。

## 四代批注者的悲剧
- **原作者**（旧墨）：发现真相的老人，花一辈子研究逃脱之法。可能已死。
- **潦草字**：实际动手者，补充操作细节。切心脉时停顿→心肌永久受损（"吾已停顿"）。代价是修炼废了。
- **细长字**：标注"此处分岔"、藏经阁后墙入口（"后墙左数第三块砖可动"）。身份不明。
- **圆字**：至少活到读第二部分，批注"难"和"门在左"。说明方向正确但极难。
- 原主是第四个找到书的人，完成了嫁接但在逆转测试时超十息而死。

## 沈渊的笔记（六条系统整理）
1. 经脉嫁接法——已验证可执行，代价：凿脉剧痛+三天空置+神识可暴露
2. 第五脉鞘——无操作说明，圆字批注"难"，原理不明
3. 终端识别术——逆转第三十七转/灵力逆行三息，临时开关。超十息则死。
4. 终端——27处分布，圆阵方向有一处。毁终端可削弱天道。
5. 原主死因推测——嫁接成功，逆转时被迫超十息（被天道发现？主动冒险？）
6. 藏经阁后墙入口——左数第三块砖可动（细长字批注确认）

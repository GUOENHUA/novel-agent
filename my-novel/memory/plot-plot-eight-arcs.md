## 八卷结构

- 第一卷「停滞」(1-100)：沈渊天才跌落，发现天道真相，加入弑天会
- 第二卷「命种」(101-200)：学习窃命术，首次黑暗选择（引爆灵脉），被天罚殿追捕
- 第三卷「天罚」(201-300)：潜入天罚殿，发现玄无极的野心，确定寻找天道本体
- 第四卷「墟」(301-400)：中点。进入上古禁地，发现天道=古人羲，获得命源碎片，决定"驯化"而非"杀死"
- 第五卷「代价」(401-500)：一切尽失。尝试控制天道反被侵蚀，墨鸦牺牲，苏九歌被俘，寿命仅剩三年
- 第六卷「逆鳞」(501-600)：突破。发现古尘遗言，创造逆鳞术，重建联盟，准备反攻
- 第七卷「弑天」(601-700)：高潮。三方混战（沈渊/玄无极/天道），沈渊牺牲自我逆转天道
- 第八卷「新生」(701-800)：结局。旧秩序崩塌，新修炼体系建立，沈渊彻底消散

**主角弧线**：干净的天才 → 染血的生存者 → 崩溃的失败者 → 重生的领袖 → 自我献祭的救赎者

**核心主题**：自由意志vs宿命、牺牲的代价、重新获得"可能性"

# 顾千帆

## 核心身份
逆种组织首领 → 断根毒素的发明者 → 天道核心分裂体的寄生者 → 试图取代天道者 → 战后教派创立者 → 最终解散教派

## 外貌
身体70%已被替换为"死的部分"——一种天道无法寄生的物质。外表冷峻，有不正常的苍白和僵硬感。部分关节处可以看到替换的痕迹。

## 性格
- 极度理性，几乎不流露情感
- 愿意为"更大的目标"牺牲任何个体——包括自己
- 内心深处的驱动力是"弑父"——她憎恨天道，因为天道既是她的寄生源，也是她存在的定义
- 全书中道德最模糊的角色：既是加害者也是受害者，既是盟友也是背叛者

## 核心创伤
- 是天道核心分裂体的寄生者——天道某种意义上就是她的"父亲"
- 为了抵抗寄生，她将自己70%的身体变成了"死的部分"——她失去了大部分感官和情感体验

## 与沈砚的关系
- **第3卷**：招募沈砚入逆种，暗中观察他
- **第4卷**：透露沈砚是"空白灵魂"，开始布局
- **第5卷**：坦白计划——让沈砚做祭品，自己取代天道。被沈砚反制
- **第7卷**：以"共犯"身份重新加入沈砚，一起登上倒悬山
- **第8卷**：战后成立天道残骸教派，最终被沈砚说服，解散教派后离开。没说谢谢。

## 关键台词候选
- 「在笼子里，没有干净的选择。」（呼应楚半阴，显示她与楚半阴本质上面对同一个困境的不同回答）
- 「你杀了我之后，打算怎么办？」（第8卷，与天道在第七卷的问题形成镜像）

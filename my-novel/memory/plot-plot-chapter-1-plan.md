# 第一章《筑基》规划

## 核心场景
沈砚冲击筑基境界，在灵气淬体的关键时刻"看到"了不该被看到的东西——隐藏在功法运转最深处的印记。

## 节奏
安静开场 → 紧张突破 → 诡异发现 → 恐惧/疑问 → 决定调查

## 策略
- 只让沈砚看到一个无法理解的诡异印记，保持神秘
- 不解释、不旁白、不揭秘
- 第三人称近距离视角
- 恐惧来自未知

## 承诺
- 基调承诺：不是传统的"修炼变强"故事
- 设定承诺：修炼体系有隐藏的黑暗面
- 角色承诺：沈砚的观察力将是他最大的武器

**Why:** 第一章需要同时完成三个任务——建立角色（沈砚的观察力/过去）、建立世界观（修炼的正常流程）、种植核心悬念（虚皇印记）。
**How:** 通过筑基这一高张力的场景自然串联三者——正常流程中插入异常发现，父亲的记忆在突破过程中自然浮现。

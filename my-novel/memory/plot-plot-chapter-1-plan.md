# 第一章规划：筑基突破中首次瞥见异常印记

## 场景级大纲

### 场景一：洞府 · 突破前夜（~500字）
- 时间：黎明前，苍梧山雾气未散
- 沈砚在山壁洞府中盘坐，面前是一枚筑基丹
- 通过身体感受展示炼气大圆满状态——经脉中灵气如溪流般饱满
- 回忆片段：三年前入苍梧宗，师傅说他"根骨尚可，但缺一点灵气"
- 吞下筑基丹，灵气开始沸腾
- **伏笔**：hook-001（对话）——师傅当年说"缺一点灵气"

### 场景二：突破准备 · 灵脉台（~600字）
- 林秋水长老已就位，护法阵开启
- 江萤在邻近灵脉节点同时冲击筑基，隔一道石壁
- 陆辰来拍肩："别紧张。"
- 林秋水叮嘱："筑基时道基与天道共振，有些人会看到幻象。那是心神不宁，不必在意。"（反讽）
- 沈砚坐下，阵法启动

### 场景三：筑基过程（核心，~1000字）
- **阶段1：液化**（~300字）——灵气如潮涌入，经脉剧痛，气态灵气在丹田被压缩液化
- **阶段2：凝结道基**（~300字）——液化灵气沉淀，意识与天道共振，世界变得透明
- **阶段3：异常闪现**（~400字）——看到金色脉络和末端符文，符文像寄生虫吸附。他试图靠近——符文察觉到他，转动如眼睛。共振结束，弹回身体。道基已成，浑身冷汗。

### 场景四：余波（~500字）
- 林秋水："成了。"
- 沈砚想描述——说不出来。不是不敢，是无法说。符文在描述时变模糊。
- 他换方式问："筑基时看到的幻象，都一定是幻象吗？"
- 林秋水："道基不稳时心神易乱，多打坐几日便好。"没有理解。
- 江萤成功筑基，看沈砚："你怎么一副见了鬼的样子。"
- **伏笔**：hook-002（直接）——"不可言说"规则

### 场景五：隐忧 · 夜晚洞府（~400字）
- 夜深独坐，尝试回忆符文。越集中越模糊。
- 但他记得：符文察觉了他。那不是死物。
- 伸出手，灵气在指尖流动。一切正常。太正常了。
- 但他再也不能假装什么都没看到。
- 结束句候选：他在黑暗中睁着眼睛，很久没有睡着。

## 第一章伏笔清单

|------|------|------|----------|----------|
| hook-001 | 对话 | 师傅说沈砚"缺一点灵气" | 场景一 | 待定（回收机制关联） |
| hook-002 | 直接 | 符文"不可言说"规则 | 场景四 | 待定（虚皇封印） |
| hook-003 | 行动 | 符文"察觉"沈砚的注视 | 场景三 | 中期（被标记） |

## 风格指导
- 开头不铺环境，直接入场景
- 筑基三段式是核心，节奏先慢后快再慢
- 异常闪现要有"瞥见"的模糊感，不能太直白
- 避免情绪词直接说明——用身体反应代替"他害怕了"

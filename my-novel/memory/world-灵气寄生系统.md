# 灵气寄生系统

## 本质
灵气不是"天地恩赐"，而是一个单向抽取系统：
- 低阶修士修炼时，一部分灵气自动向上流动至最近的高阶修士
- 高阶修士的突破消耗大量从下层抽取的灵气
- 最顶层——"天道"——是所有灵气流动的最终汇聚点

## 隐藏机制
- 所有功法底层嵌有"抽取协议"：表面是功法运行路径，实质是数据包转发规则
- 修炼境界不是自然阶梯，而是分类层级——类似生物分类学中的界门纲目科属种
- 走火入魔并非随机，而是"系统"对异常行为的免疫排异反应
- "天劫" = 免疫系统的白细胞攻击

## 关键规则
- 高阶对低阶的灵气抽取是自动的、不可感知的
- 被抽取者只会感到"威压"——这是系统提供的合理解释层
- 灵根资质 = 在系统中被分配的带宽
- 灵气潮汐 = 系统定期集中上传数据的周期

## 沈渊的发现路径
1. 首先注意到灵气流转路径过于"设计化"（第1-15章）
2. 记录数据发现单向流动模式（第16-35章）
3. 实验验证抽取现象（第36-55章）
4. 发现底层协议，被天道注意（第56-80章）

# 沈砚

## 基本信息
- 21岁现代人穿越，原职场社畜，猝死后穿越到残酷修仙世界
- 外貌：清秀偏瘦，常年挂着欠揍的笑容，眼神偶尔锐利得不像在开玩笑
- 性格：表面逗逼吐槽役，内心极度清醒冷静。用幽默解构残酷，但关键选择从不含糊
- 口头禅风格：爱用现代梗吐槽修仙世界的荒谬，但修仙者听不懂

## 核心能力：天道寄生虫
- 可以感知并"寄生"在天道的漏洞/裂缝上
- 窃取天道规则碎片：别人的悟道、天劫余波、天道遗落的信息
- 能力代价：每次寄生都会在身上留下"道痕"，积累到一定程度会引来天道的注意（天罚）
- 成长线：从被动吸附漏洞 → 主动寻找裂缝 → 进入天道内部 → 成为天道一部分/取代天道（最终选择）

## 创伤/想要/需要
- 幽灵：穿越前的平凡与不甘，穿越后的生存恐惧
- 伤口：在残酷世界中的无力感，被迫用笑脸掩盖恐惧
- 谎言："我只要苟着就行，不招惹任何人"——但实际上他做不到，因为他需要寄生天道漏洞才能变强
- 想要：安全、自由、变强后回家
- 需要：接受这个世界就是他的家了，并且他可能是唯一能修复/重塑天道的人
- 弧线：从"避世苟活"到"主动承担"，从"我是外人"到"这就是我的世界"

# 风格：慢节奏暗黑阴谋文

**核心原则：** 节奏密度偏低，不追求每章钩子。信息缓慢释放，让读者和主角一起在迷雾中摸索。氛围优先于情节推进。

**How to apply:**
- 开篇以日常和环境氛围为主，用细节营造底层修仙世界的压抑感
- 关键信息（天道真相）不要过早揭示——第一卷读者只比主角多知道一点点
- 对话中留白，不解释一切。读者需要自己拼凑
- 章节结尾可以是安静的沉思，不一定是 cliffhanger
- 情感基调：压抑、不安、偶有温暖但转瞬即逝
- 暴力场面克制但不回避——暗黑来自"体系性的残酷"而非血腥堆砌

**验证过的偏好：** 用户明确要求节奏不要太快。

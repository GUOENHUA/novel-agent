## 核心设定

**天道本质**：天道不是法则，而是上古修士"羲"创造的法术——将自己的命种植入天地法则，从此永生不死。天道寄生在每一个修士身上，通过修炼体系汲取修士的"命数"和"可能性"。飞升即被彻底吞噬。

**修行体系（九境）**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 飞升（=死亡）。每突破一境，天道取走约三成命数。到合体境，可能性仅剩一成。飞升者无人归来。

**命种机制**：天道在每个修士丹田中植入"命种"。命种在修士突破境界时绽放，抽取命数。修为越高，命种越大，被抽取越多。天才=命数丰厚=天道更"喜欢"。命种可被挖出（代价极大），可用窃命术反向汲取（需牺牲其他修士）。

**关键法术**：
- 窃命术：反向从天道偷回命数，但会触发其他修士命种提前收割
- 逆鳞术（第六卷）：逆转天道汲取方向，让修士从天道汲取命数
- 天印：天道植入天罚者体内的控制标记，赋予力量但夺取自我

**羲**：天道创造者，上古修士。意识被困在天道系统中，失去自我，只剩无尽饥饿。求沈渊杀死自己。

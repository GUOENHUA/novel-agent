## 主角：沈尘

---

### 一、核心档案

| 项目 | 内容 |
|------|------|
| **姓名** | 沈尘（"沉入尘世"——与天道的"高"形成对立） |
| **年龄** | 开篇 17 岁（宗门杂役弟子） |
| **外貌** | 身形偏瘦，常年低头——不是谦卑，是习惯性警惕。五官清秀但被杂役的灰扑扑生活磨去了棱角。左手腕内侧有一道细长的旧疤，少年时留下的，他自己也说不清来历。 |
| **身份起点** | 苍云宗杂役弟子，扫地、劈柴、给内门弟子送饭 |
| **天赋表象** | 极差——灵根检测显示"废灵根"，修炼三年仍未入练气一层 |
| **天赋真相** | 他体内寄生着一缕"天道残魂"——天道在他身上开了个口子，灵气进去九成被天道抽走，所以外部检测全是"废柴" |

---

### 二、创伤 / 想要 / 需要 / 谎言 因果链

```
【幽灵——过去的创伤事件】
七岁时目睹父亲沈牧在渡劫中"飞升"。
所有目睹者都在欢呼——又一位大能飞升了。
但沈尘看见了不一样的东西：
父亲在最后关头眼睛突然变成空洞的灰色，
嘴唇翕动，像是在说"救我"。
——然后碎裂成光，被天空"吸"走了。
那一刻的画面被七岁的沈尘压在记忆最深处，
长大后只当是童年幻觉。

【伤口——持续的情感伤害】
→ 失去父亲，成为孤儿，在宗门底层挣扎
→ 被迫接受"飞升是好事"的主流叙事，但本能地恐惧修行
→ 内心深处知道有什么不对，但找不到证据，久而久之自己也怀疑自己疯了

【谎言——角色为应对创伤而形成的错误信念】
"只要我够强，就能得到答案。"
"只要我证明自己，就不会再被抛弃。"

→ 这个谎言驱动他咬牙修炼、忍受一切屈辱
→ 但这个谎言也是天道最乐于看到的——宿主越执着于变强，天道吃得越饱

【想要——由谎言驱动的外部目标】
初期：突破废灵根限制，成为真正的修仙者，查明父亲死亡的真相
中期：挣脱天道的寄生，获得真正的自由
后期：摧毁整个寄生体系

【需要——真正能治愈角色的内部真理】
接受"有些真相不需要力量去证明"。
接受自己的脆弱不是弱点。
真正的自由不是"不被任何东西控制"，
而是"有勇气选择被什么东西束缚"。
——他最终需要的，是学会信任和联结，而非独自扛下一切。
```

**因果链核心矛盾：**
他越接近「想要」（变强），就越远离「需要」（放下），因为变强的过程就是喂养天道的过程。这是一个经典的悲剧结构——主角最好的品质（毅力、执着）恰恰是他的毁灭之源。

### 三、三滑块模型

| 维度 | 初始值 | 变化趋势 | 说明 |
|------|--------|----------|------|
| **主动性** | 6/10 | ↗ 8 | 不是天生英雄型，但遇到不公会出手。随着觉醒，从被动求生转向主动反抗 |
| **讨喜度** | 7/10 | ↗ 9 | 底层挣扎的"小人物"容易让读者共情。倔强、嘴硬心软、对弱者有天然的偏袒 |
| **能力** | 2/10 → | ↗ 8 | 表面废柴，体内藏着被天道压制的真实修为。觉醒后能力爆发式增长 |

**初始状态（卷1开篇）：** 中高主动性 + 高讨喜度 + 低能力 = 读者希望看到他赢，但他目前赢不了 → 强力阅读驱动。

### 四、性格剖面

**表层（别人看到的沈尘）：**
沉默寡言，能少说一个字就少说一个字。干杂活时手脚麻利但面无表情。内门弟子拿他撒气，他不还嘴，只是记住。偶尔有人试图对他好，他会警惕地后退一步——像是被喂过毒药的野狗。

**中层（他以为的自己）：**
"我不需要任何人。我靠自己就够了。"
对修仙世界的秩序充满怀疑，但不敢说出口。夜深人静时会反复做同一个梦——父亲空洞的灰眼睛。醒来后告诉自己：那是幻觉。

**底层（真正的他）：**
极度渴望被认可，极度害怕被抛弃。七岁失去父亲的创伤从未愈合——他不敢让任何人走近，因为走近的人最终都会离开（要么飞升，要么死去）。他的冷漠是铠甲，不是本性。

### 五、语言习惯

| 特征 | 表现 |
|------|------|
| **句子长度** | 偏短。能三个字说完不用五个字。 |
| **口头禅** | "...嗯。"（敷衍回应）、"知道了。"（实际意思是"别管我"） |
| **提问 vs 陈述** | 90% 陈述。几乎不问问题——不是不想知道，是怕暴露自己在乎。 |
| **比喻域** | 杂役的日常——劈柴、磨刀、补衣、杂草。后期逐渐加入修仙概念，但底色仍是"粗活儿"语言 |
| **称呼方式** | 对谁都很少用敬称，但不傲慢——是生疏。叫师兄师姐一律用"你"。对真正尊敬的人反而会加"前辈"。 |
| **对话风格** | 极简。但偶尔会突然说一长句击中要害的话——让周围人愣住的那种。 |

**无对话标签测试：**

> "这药能治你的伤。"
> "...嗯。"
> "你不问问我从哪弄来的？"
> "问了你会不说？"
> "...也是。"

——能看出是沈尘在说话吗？简短、不废话、回避情感交换。

### 六、与体内天道的关系动态

**天道的"人格化"设定：**
天道在他体内不是全知全能的意志，而更像一种**饥饿的本能**——它不会说话，不会谈判，不会威胁。它只是饿。它让宿主"运气好"（实际上是它在暗中优化宿主的生存概率，保证食物来源稳定），但每一次宿主调动灵力，它都会吸走九成。

偶尔，当沈尘濒死或情绪极端波动时，天道会短暂"醒来"——不是对话，而是一种压倒性的存在感：世界突然变得透明，他能看见所有人的灵气流动、看见因果线、看见万事万物的"纹理"。但这种状态只持续几息，事后他会虚脱三天。

**关系演进：**
- 卷1-2：敌人。沈尘想摆脱它，天道只是饿。
- 卷3-4：利用。沈尘学会在特定条件下"借"天道的力量，但每一次都在喂养它。
- 卷5-6：博弈。沈尘发现天道也在"饿"——它在被某种更高层的东西消耗。他们开始走向一种危险的共生。
- 卷7（最终）：选择。沈尘面临最终抉择——彻底剥离天道（代价是失去所有力量），还是与天道融合成为新的存在。

### 七、各卷成长轨迹

| 卷 | 核心转变 | 关键节点 |
|-----|----------|----------|
| **卷一（觉醒）** | 从"认命"到"发现真相"。发现自己的废柴体质不是天生的，而是被寄生的结果。第一次听到体内天道的声音——不是语言，是一种饥饿的震颤。 | 第40章左右：濒死时天道接管身体，他用出了远超认知的力量 |
| **卷二（挣扎）** | 从"想摆脱"到"被迫共存"。尝试各种方法剥离天道，全部失败。同时修仙世界开始注意到他这个"异常"。 | 第120章左右：第一次主动与天道"谈判"——用意志压制它的吸食 |
| **卷三（反抗萌芽）** | 从"独自承受"到"找到盟友"。遇到同样被天道寄生的人（柳烟等），发现这不是个例，而是一个系统。 | 第240章左右：「断天盟」前身——第一批觉醒者秘密结社 |
| **卷四（公开对抗）** | 从"藏"到"战"。寄生真相开始泄露，修仙界的根基动摇。沈尘从被追杀的异端变成公开反抗的象征。 | 第400章左右：天道第一次在众人面前显露——某个大能飞升现场，沈尘让所有人看到了"收割"的真相 |
| **卷五（旧秩序崩塌）** | 从"反抗者"到"建设者"。旧修仙秩序崩溃，但真空比压迫更可怕。觉醒者们面临选择：建立新秩序还是彻底摧毁一切？ | 第560章左右：沈尘被迫成为领导者——他最不想要的角色 |
| **卷六（终局博弈）** | 从"共生"到"最终选择"。天道寄生的终极真相被揭开——天道之上还有更高层的东西。沈尘面临选择：剥离天道成为凡人，或融合天道成为新的存在。 | 第780章左右：最终抉择 |

### 八、核心张力点

1. **每一分力量都有代价** — 沈尘每次使用力量，都在喂养体内的寄生虫。他永远不能毫无顾忌地战斗。
2. **信任恐惧** — 他害怕与人走近，但反抗寄生体系必须依靠他人。他的个人创伤与使命之间存在结构性矛盾。
3. **"如果天道是对的怎么办"** — 随着剧情深入，沈尘会面对一个可怕的问题：也许寄生不是剥削，而是某种他不知道的共生？也许天道也在被更上层的东西寄生？

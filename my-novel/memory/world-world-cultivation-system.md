# 修炼体系

## 境界序列（从低到高）

| 境界 | 关键特征 | 寿命 |
|------|----------|------|
| 感气 | 感知天地灵气存在 | 凡人 |
| 炼气（9层） | 引灵气入体，淬炼经脉 | 120岁 |
| **筑基** | 灵气液化，铸就道基。**第一次触碰天道规则** | 300岁 |
| 金丹 | 灵气固化，凝结金丹 | 800岁 |
| 元婴 | 丹破婴生，元神初成 | 3000岁 |
| 化神 | 元神大成，神识外放 | 5000岁 |
| 合体 | 身道合一 | 万年 |
| 大乘 | 半步飞升 | 三万年 |
| 渡劫 | 天劫淬体，飞升成仙 | — |

## 筑基的本质（核心）
- 感气和炼气都是在"用"灵气——像呼吸空气
- 筑基需要将灵气**液化**——固化在自身内部
- 液化过程中，道基与天道短暂共振
- **这个共振窗口是唯一能天然触及天道底层的机会**——金丹以上也无法复现
- 沈砚正是在这个窗口中瞥见了虚皇的符文

## 功法体系
- **心法**（主修）：决定灵气运行路径和属性偏斜
- **术法**（战斗）：具体招式，受心法约束
- **秘术**（稀有）：超越常规规则的术法，往往有代价

## 苍梧宗功法特点
- 木系主导：苍梧山有万年古木，木灵气浓郁
- 心法温和稳健，适合中等资质修士
- 缺乏顶级功法——这也是苍梧宗无法跻身一流的根本原因

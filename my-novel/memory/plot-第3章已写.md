# 第3章「药田」关键事件

**事件：**
1. 沈渊利用三天空闲展开主动调查，前往药田观测灵气流动
2. 发现药田植物体内灵气持续外流，方向斜上指向山腰下方——非垂直、非随机
3. 灵气浓度分布异常：边缘高、深处低，违反直觉——暗示抽取源距药田有一定距离
4. 雾退方向与灵气外流方向一致，均指向分叉口右侧小路
5. 丹田出现短暂共鸣（半圈），有人在下方的某个地方动用灵气
6. 决定次日探查右侧小路；仍需找到瘦长脸获取原主"新法子"信息

**Why:** 沈渊从被动观察转向主动调查。药田数据为他提供了第一个独立验证假设的证据。方向性（斜上而非垂直）暗示抽取源是局部的——可能是宗门内某个设施或人物，而非遥远的"上天"。

**How to apply:** 第4章应推进右侧小路的探查，可能引入新角色或第一个具体对抗。同时需要让瘦长脸再次出现，提供"新法子"线索。丹田共鸣暗示了某种探测能力——沈渊可能开始发展对灵气活动的感知力。

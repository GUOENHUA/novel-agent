# 八卷结构

## 三幕划分
- **第一幕（建置）**：卷1-2（1-200章）。发现真相，挣扎求生。
- **第二幕（对抗）**：卷3-5（201-500章）。逆天而行，代价步步升级。
- **第三幕（解决）**：卷6-8（501-800章）。全面战争，弑天，劫后。

## 各卷核心
- **卷一：觉醒**（1-100）→ 发现寄生的蛛丝马迹，第一次不可逆决定（献祭母亲记忆）
- **卷二：虫窟**（101-200）→ 深入地下组织，看到人性阴暗面，虫窟覆灭
- **卷三：逆种**（201-300）→ 加入激进组织，道德滑坡，第一次听到天道声音
- **卷四：代价**（301-400）→ 追溯身世，发现母亲真相，同意以自身为实验体
- **卷五：共主**（401-500）→ 揭示天道起源，顾千帆背叛被反制，天道首次受伤
- **卷六：裂痕**（501-600）→ 全面战争，众生觉醒，三方势力，被战友背叛
- **卷七：弑天**（601-700）→ 登上倒悬山，与天道融合，弑天成功但失去自我
- **卷八：余孽**（701-800）→ 劫后漫游，最终对决顾千帆，开放式结局

## 关键转折点
- 引发事件：目睹飞升真相（卷1，~22章）
- 第一次不可逆：献祭母亲记忆（卷1末，~95章）
- 虫窟覆灭（卷2末，~180章）
- 飞升大典惨案（卷3末，~290章）
- 母亲真相揭露（卷4，~360章）
- 天道起源揭示（卷5，~450章）
- 沈砚反制顾千帆（卷5末，~500章）
- 全球觉醒/三方战争（卷6，~530-590章）
- 天道最后通牒（卷6末）
- 登上倒悬山（卷7，~630章）
- 弑天（卷7末，~695章）
- 最终与顾千帆对峙（卷8，~780章）

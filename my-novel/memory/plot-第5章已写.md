第5章「封禁」关键事件：
1. 刘管事用封灵阵（横三竖三松木板+四角阵钉）封死矿口，宣布停工检修工期不定，矿工按半日结算去账房领钱。刘管事离开前特意看了沈渊一眼——管事堂已标记他。
2. 赵老四画出第四层铁链上的封禁符文——形似倒置"囚"字，全是直线拐角，非青云宗符法风格。沈渊判断为摹写自更古老的东西。
3. 沈渊在废弃藏经阁找到两份关键文献：八十年前"丙区旧档"（红笔记录丙四层遇黑色硬层停工七日）和古籍《壳虫说》残简（描述壳虫"生于地脉，无首无足，唯壳而已。壳色玄黑，湿泽如膏，触之温。壳内空，有气出入，三息一至。古修士谓之地龙蜕"）。
4. 沈渊拿走丙区旧档纸卷。他向赵老四提出条件——破开封禁后要看赵老四哥哥的骨头。
5. 三息脉冲不随距离衰减——离矿越远仍在脑中清晰。沈渊怀疑脉冲在"找他"。

Why: 本章将信息发现从物理观察推进到文献证据层面，建立管事堂系统性隐瞒的时间深度（至少八十年），同时引入更古老的知识体系（壳虫说/地龙蜕）。脉冲不衰减暗示沈渊与壳之间存在特殊连接——这是角色命运层面的重要伏笔。

How to apply: 第6章可写去账房领工钱（遇到新角色/信息），以及沈渊夜间分析丙区旧档中的更多异常数据。第7-10章逐步回收hook-013（债务）和hook-035（旧档分析）。

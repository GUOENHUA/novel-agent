# 第5章「树洞」关键事件

## 主线推进
- 沈渊辰时趁人多前往槐树洞，取出油纸包——内有三张原身破障法实验记录
- 原身记录揭示：抽取有节奏（每七息）、有接收者（"有人在接"）、运功后激活的抽取独立于修炼者（"开关不在我手上"）
- 原身运功时眼睛变灰白，陈玄说"像是有人在从眼睛里往外看"
- 原身记录：不练功也能感到上方有东西在"偶尔扫一眼"
- 原身统计：宗门数千年外门突破速度误差不超过两人——"不是稳定，是有人在管"
- 最后一行"脚印就是——"被水渍糊掉，沈渊怀疑是某种力量不准它留存
- 铜符弟子进过沈渊房间，在床板记录末尾用刀尖刻下"未必是人"——接在"陈玄眼白干净"之后
- 窗缝被嵌碎木头堵窄——沈渊推测铜符弟子在帮他减少被"上面"观察的风险
- 沈渊形成新假说：铜符弟子在演给上面看，实际在保护沈渊
- 新问题链：修路的不是人？修道的也有不是人的？——陈玄可能不在聚灵阵抽取系统内

**Why:** 信息量最大的一章——原身完整推论 + 铜符弟子身份反转。破障法从"修炼技巧"升级为"激活独立实体的仪式"。铜符弟子从压迫者变为可能的保护者，动机仍需揭示。
**How to apply:** 第6章需处理铜符弟子关系的下一步——沈渊会试探铜符弟子吗？陈玄的"非人"线索需要更多证据。"脚印"的含义是远期核心谜题。

### 二、天劫本质

天劫不是考验。是**调节阀**。

```
修士突破速度太快 → 天道降下大天劫 → 一次性榨干（劈死）
修士突破速度太慢 → 天道制造瓶颈 → 持续缓慢抽取（慢性死亡）
修士突破速度"适中" → 标准天劫 → 抽取70-90%本源，给修士留一口继续修炼
```

天劫的规模不是由"天道意志"决定的——是自动机制。天道像一个巨大的自动运行系统，它没有情绪，只有规则。这也是主角后来能找到漏洞的原因：规则就可以被利用。

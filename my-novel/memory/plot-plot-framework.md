# 《天道寄生虫》大纲框架

800章 / 暗黑阴谋文 / 核心设定：天道即寄生虫

## 第一卷：观棋者（1-200章）
主线：底层散修主角在修仙界挣扎求生，偶然窥见天道的裂痕。开始意识到修炼的代价不只是努力和天赋。不确认"反向寄生"是否可行——只确认天道在寄生所有人。

| 节段 | 章范围 | 核心 |
|------|--------|------|
| 开篇 | 1-30 | 底层散修日常，残酷修仙法则。主角第一次与天道产生隐晦"接触" |
| 裂缝 | 31-80 | 天才陨落、渡劫者失踪。天道收割露出冰山一角 |
| 觉醒 | 81-140 | 发现前辈残魂/禁书证据。主角面临选择：装傻苟活 vs 追查 |
| 抉择 | 141-200 | 选择追查。天道察觉异常。第一卷以发现体内有"天道之种"结束 |

## 第二卷：笼中囚（201-500章）
主线：主角深入调查，发现上古反天道遗迹。但每次"进展"可能都是天道设计的陷阱。不确认能否反制，只能挣扎求存。

## 第三卷：噬天者（501-800章）
主线：开放结局方向。可能反制成功，可能彻底失败，可能选择第三条路。不预设答案。

Why: 用户明确表示"不一定要有反向寄生"，保持叙事开放性和真正的黑暗感。
How: 每一卷主角都在尝试"可能的出路"，但每一个出路都充满不确定性和代价。

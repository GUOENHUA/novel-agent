# 第9章已写

## 时间
穿越后第3天深夜（第8章同一天晚上）

## 关键事件
1. **井边三向实验**：沈渊深夜独自到老井边，三向同时按压脉门（大拇指往上、食指往指尖、三指往下），发现灵根主方向往上（生长方向），聚灵阵往下抽是外力
2. **灵根中轴发现**：推导出灵根贯穿涌泉→百会的中轴，手腕脉门只是接口，根头在脚底涌泉
3. **井水拉灵根**：手指浸入井水时，灵根被井水拽出一小截——井水里的灵气往下走，与聚灵阵方向相同，合力拽灵根
4. **断根正路推导**：断根不在手腕（堵接口），而在脚底涌泉（掐根头）。但直接按涌泉会触发聚灵阵反推
5. **陈玄机制揭示**：陈玄不直接按涌泉，而是手按土通过暗河从地底往上顶涌泉——暗河不在聚灵阵范围内，信号不被感知。左手无名指小指持续按压49年，一天没停
6. **井水＝断根工具**：井水连着暗河，手腕浸井水→灵根被拉进水路→进暗河→出系统→灵根瘪掉
7. **灰墙节奏确认**：墙里东西每七八息动一下，和聚灵阵同频。那只手的碎片在墙里往外推

## 新揭示
- 灵根生长方向（往上）vs 聚灵阵抽取方向（往下）——两个方向在脉门打架
- 暗河是系统盲区——不在聚灵阵覆盖范围内
- 井水是直接断根通道，比陈玄的间接按压更高效
- 陈玄的左手持续动作不是抽筋，是按压暗河信号

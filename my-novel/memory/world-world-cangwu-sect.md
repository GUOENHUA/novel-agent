# 苍梧宗

## 基本定位
- **等级**：二流宗门
- **位置**：东荒苍梧山
- **特长**：木系功法（苍梧山有万年古木，木灵气浓郁）
- **氛围**：温和、守成、缺乏野心。在修真界属于"不被盯上也无人敬畏"的类型

## 结构
- **外门**：感气 → 炼气中期（约500人）
- **内门**：炼气后期 → 筑基（约80人）
- **真传**：金丹种子（个位数）
- **掌门**：元婴初期，已闭关百年（名字待定）
- **金丹长老**：仅三位，林秋水是其中之一

## 灵脉
- 苍梧山地下有木系灵脉，品质中等偏上
- **关键**：这条灵脉恰好是虚皇回收机制的**一个末端节点**
- 宗门上下无人知晓——包括掌门
- 灵气从灵脉中被悄然抽走，但抽走的量被精确控制——不至于让灵脉枯竭，但足以限制宗门的整体修炼速度

## 叙事意义
- 二流宗门的设定给沈砚喘息空间——如果在一流大宗门，异常容易被察觉和镇压
- 苍梧宗的"温和守成"是虚皇系统的缩影——整个修真界都被驯化在一个看不见的牢笼里
- 灵脉的末端节点身份意味着：沈砚的发现不是巧合，而是必然。他在正确的地方筑基
